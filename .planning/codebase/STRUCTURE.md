## Path Alias

Single TypeScript path alias (`tsconfig.app.json`):

```
@/*  →  src/*
```

Imports use it consistently: `import { useSessionStore } from '@/shared/session/store'`. Relative imports (`./`, `../`) are reserved for files in the same folder.

## Naming Conventions

| Kind | Convention | Examples |
|---|---|---|
| React components | `PascalCase.tsx` | `AppShell.tsx`, `RoleGate.tsx`, `ProfileMenu.tsx` |
| Hooks | `useXxx.ts` (camelCase, prefixed `use`) | `useTheme.ts`, `use-mobile.ts` (kebab-case for shadcn-derived hooks) |
| Stores | `xxxStore.ts` (camelCase) | `uiPrefsStore.ts`; session uses `store.ts` inside the `session/` folder |
| Pure helpers / libs | `camelCase.ts` | `money.ts`, `cn.ts`, `date.ts`, `plural.ts` |
| Types-only modules | `types.ts` inside the feature folder | `session/types.ts` |
| Tests | Co-located, suffixed `.test.ts(x)` | `money.test.ts`, `can.test.ts`, `session-swap.test.ts` |
| Routes | TanStack file-based (`src/routes/foo.tsx` → `/foo`) | `clients.tsx`, `index.tsx`, `__root.tsx` |
| Fixtures | `__fixtures/` (excluded from lint + test) | `api-mode-leak.ts`, `raw-palette.tsx` |
| Folders | `kebab-case` for multi-word | `app-shell/`, multi-word features will follow this |
| Barrel exports | `index.ts` only at folder boundaries (e.g. `app-shell/index.ts`, `services/mock/index.ts`) | |

## Where to Add New Code

| Adding… | Goes in | Notes |
|---|---|---|
| A new top-level page | `src/routes/<name>.tsx` | TanStack file-based; gate access in `beforeLoad` via `can()` |
| A new feature (e.g. clients CRUD) | `src/features/<domain>/` with `api/`, `components/`, `model/`, `index.ts` | Cannot import from another feature |
| A domain entity (types + Zod schema + helpers) | `src/entities/<entity>/` | Reused across features and the mock/http impls |
| A reusable UI primitive | `src/shared/ui/` | Don't hand-edit shadcn files; wrap them |
| A cross-cutting helper | `src/shared/lib/` | Pure functions only |
| A new mock service | `src/shared/api/services/mock/<resource>.ts` then export from `mock/index.ts` | Honor latency + role enforcement contract |
| A new HTTP service | `src/shared/api/services/http/<resource>.ts` then export from `http/index.ts` | Same contract shape as mock |
| A new role/permission | `src/shared/session/can.ts` (`OWNER_ONLY` matrix) and `registry.ts` if a new resource | Update `can.test.ts` |
| A new translation | `src/shared/i18n/ru.ts` | Single dictionary, no other files |

## Storage Keys

Versioned `localStorage` keys (all prefixed `sportzal:`):

| Key | Owner | Purpose |
|---|---|---|
| `sportzal:session:v1` | `src/shared/session/store.ts` | Persisted role |
| `sportzal:ui:v1` | `src/shared/theme/uiPrefsStore.ts` | Theme preference |
| `sportzal:mock:v1` | `src/shared/api/services/mock/` (planned) | Mock DB snapshot |

Bump the suffix (`v1` → `v2`) when shape changes; provide a `migrate` function in the store config.

## Generated / Do-Not-Edit Files

- `src/routeTree.gen.ts` — regenerated by `tanstackRouter` plugin on every build/dev start. Carries `@ts-nocheck` and is gitignored from lint (`eslint.config.js:16`).
- `dist/` — Vite build output. Gitignored.
- `node_modules/` — pnpm install output. Gitignored.
