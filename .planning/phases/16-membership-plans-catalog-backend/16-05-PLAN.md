- GET /api/v1/membership-plans -> 200 + ResponseEnvelope[PaginatedData[MembershipPlanResponse]]
- GET /api/v1/membership-plans/{plan_id} -> 200 / 404 plan_not_found

- DELETE /api/v1/membership-plans/{plan_id} -> 204 / 404 plan_not_found
All 4 mutating + GETs are owner-only -> 403 for reception, 401 for unauth.

Wire shape (clients precedent):
- Request bodies: camelCase (durationDays, priceKopecks)
- Response: ResponseEnvelope wraps {data: ...}; PaginatedData fields {items, total, page, pageSize}
- Error envelope: {code, message} (e.g. {"code":"plan_name_exists","message":"..."})
- CSRF header: X-CSRF-Token, value from cookies['sportzal_csrf']

- root conftest provides: db_session (SAVEPOINT-mode async session), app factory, async_client (httpx.AsyncClient with ASGITransport)
