## Collision-Set Details

Pre-flight analysis of the current corpus revealed 4 stripped names that collide because two router files define Python handlers with identical names:

| Stripped name | Router 1 (tag: membership-plans) | Router 2 (tag: pt-package-plans) |
| ------------- | --------------------------------- | --------------------------------- |
| list_plans | GET /api/v1/membership-plans | GET /api/v1/pt-package-plans |
| create_plan | POST /api/v1/membership-plans | POST /api/v1/pt-package-plans |
| get_plan | GET /api/v1/membership-plans/{plan_id} | GET /api/v1/pt-package-plans/{plan_id} |
| update_plan | PATCH /api/v1/membership-plans/{plan_id} | PATCH /api/v1/pt-package-plans/{plan_id} |

D-64-OPID-COLLISION fallback applied: tag prefix prepended (hyphens → underscores via `re.sub(r'[^a-z0-9]', '_', str(route.tags[0]).lower())`):
- `membership-plans` → `membership_plans_list_plans`, `membership_plans_create_plan`, etc.
- `pt-package-plans` → `pt_package_plans_list_plans`, `pt_package_plans_create_plan`, etc.

All other 99 routes use the simple strip (no prefix).
