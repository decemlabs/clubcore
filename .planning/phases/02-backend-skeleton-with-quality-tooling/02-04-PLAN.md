         service.py/models.py/schemas.py with TODO. NO User/RefreshToken models.

MOD-02 — Other 8 modules: only __init__.py exist; rest is empty.

MOD-03 — modules cannot import each other (verified by import-linter
         independence contract, set up in Plan 01). This plan must NOT introduce
         any cross-module import.

RESEARCH.md Pitfall 5 — Empty __init__.py may not be picked up by import-linter's
grimp graph builder. To make the `independence` contract actually exercise these
packages, each module __init__.py must have at least one importable symbol or
import statement. Solution: make auth/__init__.py do a "noqa F401" re-import of
its own submodules; for the other 8 modules use a one-line module docstring
(grimp does parse docstring-only files, but the safer pattern is an empty file
and rely on the modules being imported transitively when api/v1/router.py
includes auth_router; for Phase A where only auth has any code at all, the
pragmatic approach below uses docstrings).

Decision for this plan: Each module __init__.py gets a one-line module docstring.
This is enough for grimp to register the package, satisfies "empty of business
logic" per MOD-02, and avoids the noqa-import dance.
