**§2 — Payroll golden-path (owner-only).** 4 steps:
1. Owner login + cookies.txt jar (lifted from v1.8 §2.1).
2. `PUT /api/v1/payroll/trainer-configs/{trainer_id}` — set a fixed-rate or
   percentage compensation config with known fixture rate (e.g. 500 kop/session
   fixed OR 30% revenue share). Expected: 200 + config payload.
3. `GET /api/v1/payroll/preview?fromDate=...&toDate=...` — read-only accrual
   preview for known fixture period. Operator eyeball-matches expected kopeck
   total against fixture seed (operator-pending — exact number lifted from
   `apps/backend/tests/integration/payroll/` test constants).
4. `POST /api/v1/payroll/accruals` — append accrual ledger entry for the same
   period. Expected: 201 + accrual entity with ID.
5. `POST /api/v1/payroll/accruals/{accrual_id}/mark-paid` — mark accrual paid.
   Expected: 200 + paid timestamp.
Each step includes the fenced curl with cookies.txt + CSRF header + Content-Type.

**§3 — Recurring schedule + time-off golden-path (owner-only).** 4 steps:
1. `POST /api/v1/recurring-templates` — create recurring template with known
   weekday + time window. Expected: 201 + template ID.
2. `GET /api/v1/recurring-templates` — paginated list shows the new template.
3. `POST /api/v1/time-off` — create time-off block overlapping the recurring
   window. Expected: 201 + time-off ID.
4. `GET /api/v1/time-off` — paginated list shows the new block.
5. `POST /api/v1/recurring-templates/{template_id}/deactivate` — deactivate
   template; expected: 200 + `is_active: false`.
6. `DELETE /api/v1/time-off/{time_off_id}` — delete time-off; expected: 204.
Operator note: confirm slot generation respects time-off windows per REC-04 /
TOFF-03 acceptance — eyeball check against `GET /api/v1/trainer-slots` for the
overlapping window.

**§4 — Trainer-usage report (owner-only, JSON + CSV/Excel).** 3 steps:
1. `GET /api/v1/reports/trainers?fromDate=...&toDate=...` — JSON response.
   Operator eyeball-matches `session_count`, `revenue_kopecks`,
   `total_accrued_kopecks` against the fixture seed (operator-pending — exact
   numbers lifted from `apps/backend/tests/integration/reports/test_trainers_report.py`
   or equivalent golden constants).
2. `GET /api/v1/reports/trainers.csv?fromDate=...&toDate=...` — download CSV
   with `Accept: text/csv`. Save to local file `trainers.csv`.
3. Open `trainers.csv` in Excel (Windows) or LibreOffice Calc / Numbers (macOS).

   - Cyrillic trainer names render without `?` or `Ã` (BOM intact —
     UTF-8 BOM + RFC-4180 dialect per Phase 60 D-60-11).
   - Kopeck columns render as integers; date columns as `YYYY-MM-DD`.
