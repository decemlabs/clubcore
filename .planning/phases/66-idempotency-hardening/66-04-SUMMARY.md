# Phase 66 Plan 04: IDM-04 IdempotencyKey OpenAPI Parameter — CATEGORY_A_OPERATION_IDS + Regen

**One-liner:** `components.parameters.IdempotencyKey` added to the frozen spec via `_customize_openapi` post-processor using the imported `IDEMPOTENCY_KEY_PATTERN` constant; all 22 category-A operations carry `$ref: '#/components/parameters/IdempotencyKey'`; openapi.json + schema.d.ts regenerated byte-stably with drift gate and Redocly lint clean.

## What Was Done

### Task 1: Declare CATEGORY_A_OPERATION_IDS + inject IdempotencyKey in _customize_openapi

**Import added:**

```python
from app.core.idempotency import IDEMPOTENCY_KEY_PATTERN
```

This is the IDM-02 lockstep: the runtime validation regex and the spec schema pattern share the same object. Divergence is impossible by construction — no literal string is re-typed in `main.py`.

**`CATEGORY_A_OPERATION_IDS` frozenset declared alongside `PUBLIC_ENDPOINT_OPERATION_IDS` (22 entries):**

```
cancel_booking, cancel_membership, cancel_pt_package, cancel_pt_session,
cancel_slot, create_booking, create_membership, create_pt_package,

sell_pt_package_qr, sell_pt_package_redirect, unfreeze_membership
```

Sourced verbatim from `.planning/handoff/v1.11-idempotency-audit.md`. The 4 IDM-07 additions from 66-03 (`cancel_membership`, `freeze_membership`, `unfreeze_membership`, `renew_membership`) are included. The 2 online refund endpoints (`refund_membership_online`, `refund_pt_package_online`) are excluded (B-class, DB-guarded per audit).

**`_customize_openapi` extended (before per-op walk):**

Injects `components.parameters.IdempotencyKey`:
- `name: "Idempotency-Key"`, `in: "header"`, `required: true`
- PITFALLS-C-05 description: cached response is at time of first successful execution; retries replay verbatim; for current state use GET endpoint
- `schema: {"type": "string", "pattern": IDEMPOTENCY_KEY_PATTERN}` — pattern byte-identical to runtime validation

**Per-op walk extended (inside existing loop):**

```python
if op.get("operationId") in CATEGORY_A_OPERATION_IDS:
    params: list[object] = op.setdefault("parameters", [])
    if idem_ref not in params:
        params.append(idem_ref)
```

Idempotent: if `$ref` is already present (e.g., FastAPI emitted it somehow), it is not doubled.
