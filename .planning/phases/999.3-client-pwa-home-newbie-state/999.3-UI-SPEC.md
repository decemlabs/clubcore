## Spacing Scale

All values come from the approved mockup and the existing spacing in `HomeScreen.jsx`. The app uses 8-pt multiples with a few 10/12px exceptions in tight UI areas.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline label gaps, dot / pin decorations |
| sm | 8px | Gap between onboarding step chips; gap between step icon and label |
| md | 12px | Section bottom margins (hero, onboard-card, booking nudge, QR placeholder); icon-to-text row gaps |
| lg | 16px | Screen horizontal padding (all sections); tile grid padding-bottom |
| xl | 20px | Hero card vertical padding (bottom); QR button padding |

Exceptions:
- Onboarding step chips: `min-width: 124px`, horizontal scroll, `padding: 10px 12px 11px` (tight card feel matching mockup).
- Hero CTA button: `height: 50px`, `border-radius: var(--r-pill)` — matches `.btn` base height.
- QR placeholder row: `padding: 10px 14px` (slim read-only strip, not a tappable card). Hero card inner padding is `22px 22px 20px` (side/top values are single-use component values, not reusable grid tokens).
- Tile grid: `gap: 10px` (10 not 8 — matches existing `HomeClassic` `QuickTile` grid).
- Progress track: `height: 6px` (same as existing `.progress-track`).

All exception values (10px, 11px, 6px, 50px) are verbatim from the approved mockup (`home-newbie.html`) and the existing `styles.css`/`HomeScreen.jsx` — these are pre-existing values from the approved design authority, not new spacing tokens invented for this phase.

| Text secondary | `var(--text-2)` | `#57534e` | Hero body (mixed), step meta, gym pill label, QR placeholder title |
| Text tertiary | `var(--text-3)` | `#a8a29e` | Eyebrow labels, step meta (inactive), QR lock icon, tab bar inactive |

**Accent reserved for:**
- Hero CTA button background ("Выбрать абонемент")
- Onboarding progress bar fill
- Completed step (`.step.done`) background tint and icon fill
- Animated pulse dots (hero eyebrow dot, gym pill dot)

**Dark theme:** The app ships a `[data-theme="dark"]` warm-espresso override in `styles.css`. The newbie state inherits it automatically because all color references use CSS variables. No dark-specific overrides needed in new code.

**Hero card (`var(--text)` background):**
- Two decorative pseudo-shapes using `radial-gradient` with `var(--accent)` at opacity ≈ 0.75 and a white glow at 0.05 — purely presentational, implemented as absolute `div.hero-shape` and `div.hero-shape-2`.
- Hero body text opacity: `color-mix(in oklab, var(--bg) 78%, transparent)` — renders as semi-opaque cream on the dark card.
- Hero eyebrow opacity: `color-mix(in oklab, var(--bg) 60%, transparent)`.
- Hero CTA text: `#06120c` (near-black for contrast on accent green).

## Component Inventory

New components to add to `HomeScreen.jsx` (or inline as named exports):

### `HomeNewbie`
The top-level variant rendered when `homeData?.membership === null`.

**Props:**
- `onOpenPlans: () => void` — navigates to Plans sheet

- `onTab: (tab: string) => void` — switches bottom tab ('book' | 'chat')

**Render order (top to bottom):**
1. Header (greeting + name + GymStatusPill) — reuse existing pattern
2. `HeroNewbie` card

### `OnboardingStrip`
Dismissible card with 4 step chips and a progress bar.

| Step | State | Icon | Label | Meta |
|------|-------|------|-------|------|
| 1 — Аккаунт | done | checkmark | "Аккаунт" | "Создан" |
| 2 — Абонемент | pending (next) | card/payment | "Абонемент" | "Не выбран" |
| 3 — Профиль | pending | person | "Профиль" | "Фото, рост, вес" |

Progress bar: 25% fill (1 of 4 complete) → CSS `width: 25%` on `.onboard-fill`.

Header: eyebrow "Старт новичка", title "Ещё 3 шага до полного старта", count badge "1 / 4", dismiss × button.

Dismiss interaction: adds `.dismissing` class → `onboard-collapse` keyframe animation (360ms) → `display: none` or remove from DOM. State: `const [dismissed, setDismissed] = React.useState(false)`. Render nothing when dismissed.

Chips scroll horizontally on overflow (`overflow-x: auto`, `scrollbar-width: none`). Each chip taps to the relevant action (Step 2 → `onOpenPlans`, Step 3 → `onTab('profile')`, Step 4 → `onTab('book')`). Step 1 (done) — no action.

## Interaction Contract

### Conditional render gate
`HomeScreen.jsx` currently dispatches on `tweaks.homeVariant`. The newbie state is keyed on subscription status, NOT on a tweaks variant.

```
if (homeData?.membership === null || homeData?.membership === undefined) → render <HomeNewbie>
else → render existing variant dispatch (classic / qr-hero / minimal)
```

This check runs after `isLoading` and `isError` guards, using the real API response. `toSubInfo(null)` already signals the empty state; the newbie render branch replaces the full content area, not just the sub card.

### Animation
- All newbie sections enter with `fade-up` + staggered delays (matching mockup):
  - Header: `d0` (no delay)
  - `HeroNewbie`: `fade-up d1` (0.05s delay)
  - `OnboardingStrip`: `fade-up d2` (0.10s delay)
  - `FirstVisitNudge` + `QrPlaceholder`: `fade-up d3` (0.15s delay)
  - Tiles: `fade-up d4` (0.20s delay)
- Dismiss animation: `onboard-collapse` keyframe (see mockup CSS) → 360ms → remove card from DOM.
- Hero eyebrow dot pulse: `pulse-soft 2.4s ease-in-out infinite` (keyframe already in `styles.css`).
- Gym pill dot pulse: same `pulse-dot` / `pulse-soft` pattern (7×7px, `#10b981` active green tint).

### Press states
- `HeroNewbie` CTA: `.btn:active { transform: scale(0.98); }` (existing `.btn` rule).
- `FirstVisitNudge`: `.press:active { transform: scale(0.985); }` — add `.press` class.
- Onboarding step chips: `transform: scale(0.985)` on active — mirror existing step CSS.
- `QrPlaceholder`: no press state (static, non-interactive `div`).
- Quick tiles: existing `QuickTile` component — unchanged.

### Pull-to-refresh
`<PullToRefresh>` wrapper is already present in `HomeScreen`. The newbie state renders inside it — no change needed.

### Reduced motion
`@media (prefers-reduced-motion: reduce)` in `styles.css` collapses all animations to 0.001ms. All new animations inherit this automatically.
