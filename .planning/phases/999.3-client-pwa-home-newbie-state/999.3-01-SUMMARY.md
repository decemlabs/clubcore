## What Was Built

### Task 1 — `client_has_any_membership` repository reader

Added `async def client_has_any_membership(session, client_id: UUID) -> bool` to `repository.py`:
- Uses `SELECT EXISTS(SELECT 1 FROM memberships WHERE client_id = :client_id) AS ever`
- Raw `text()` only — no ORM import of `Membership` (D-54-08/D-20-MODULE)
- IDOR-safe: mandatory `:client_id` bind cast to `str`
- Name added alphabetically to `__all__` tuple

### Task 2 — Schema field + service derivation

`schemas.py` — `ClientHomeResponse` extended with `membership_state: str` (wire: `membershipState` via `ResponseData`'s `to_camel` alias generator, same as `expiring_soon`→`expiringSoon`).

`service.py` — `get_client_home` updated:
```python
ever = await repository.client_has_any_membership(session, client_id)
state = "active" if membership is not None else "lapsed" if ever else "newbie"
return ClientHomeResponse(..., membership_state=state)
```
No `session.commit()` (read path). No try/except (AppError bubbles).

### Task 3 — Integration tests

Three assertions in `test_read_endpoints.py`:
- **NEWBIE**: `test_home_composite_empty_client_returns_null_slots` extended — asserts `membershipState == "newbie"` for client with zero membership rows
- **LAPSED**: new `test_home_membership_state_lapsed` — seeds a client with `status='expired'` membership, asserts `membershipState == "lapsed"`
- **ACTIVE**: `test_home_composite_with_data_returns_fields` extended — asserts `membershipState == "active"` for seeded `client_a`
