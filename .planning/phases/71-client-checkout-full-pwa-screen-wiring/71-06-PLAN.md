## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-71-26 | Tampering / replay | QR token replay | mitigate | Token is short-lived signed JWT issued server-side (Phase 70 CCHK-01/03); PWA only displays it; anti-replay enforced server-side. PWA refreshes before TTL |
| T-71-27 | DoS / double-book | duplicate booking submit | mitigate | `useCreateBooking` sends per-intent Idempotency-Key (CBOOK-03); server partial-UNIQUE arbiter returns 409 on concurrent dup (Phase 70) |
| T-71-28 | Information Disclosure | cross-client booking access | mitigate | Book endpoints are IDOR-safe server-side (Phase 70 D-20-IDOR); PWA reads only own bookings via session cookie |
| T-71-29 | Spoofing | booking without PT-package | mitigate | Server rejects (CBOOK-04); PWA routes to Plans/Checkout rather than leaking a raw error |
</threat_model>
