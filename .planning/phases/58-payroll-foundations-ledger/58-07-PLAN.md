<objective>
Deliver PAY-03 (record accrual) + PAY-04 (mark paid). The accrual row snapshots
the resolved rate/config + computed components at run time (D-58-03, never
recomputed). Run idempotency is DB-wins-the-race via ON CONFLICT DO NOTHING
RETURNING (D-58-06, no SELECT-then-INSERT). Mark-paid is the single allowed
post-INSERT mutation (D-58-08), gated by SELECT FOR UPDATE; second attempt 409.

Purpose: Append-only payroll ledger with financial-correctness guarantees —
the persisted accrual numbers are byte-identical to the PAY-02 preview because
both call `compute_accrual_components`.

Output: Two repository writers, two service orchestrators, two owner-only
endpoints, and integration tests proving idempotency, snapshot immutability,
and the single-transition lifecycle.
</objective>
