- GET   /api/v1/client/messages           ?page=N&after=<uuid>  → { data: { items, total, page, pageSize, unreadCount } }

- POST  /api/v1/client/messages/attachments  multipart/form-data field `file` → { data: { attachmentId, previewUrl } }

- WS    /api/v1/client/ws/messages        cookie auth on upgrade → server-push frames

MessageItem camelCase fields on the wire:
  id: string; role: 'client'|'staff'; body: string; sentAt: string; readAt: string|null;
  threadId: string; attachment: { id, mimeType, sizeBytes, url } | null
  (attachment.url = /api/v1/client/messages/attachments/{id})

WS frame shapes (camelCase):
  { "type": "new_message",  "messageId": "<uuid>" }
  { "type": "read_receipt", "readAt": "<ISO datetime>" }  ← send-time WATERMARK, NOT a read clock
  { "type": "typing",       "actor": "staff" }
  { "type": "ping" }                                       ← server heartbeat, no client action

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → REST (/api/v1/client/messages*) | client-supplied body/attachmentId crosses here; ownership derived server-side from cc_client_access only |
| browser → WS (/api/v1/client/ws/messages) | WS upgrade authenticated by httpOnly cookie + Origin check (server-side, Phase 90) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-94-01 | Spoofing | WS connection | accept | Auth + Origin check enforced server-side at upgrade (Phase 90); client opens same-origin URL only, no token in URL |
| T-94-02 | Information disclosure | WS frame handling | mitigate | onmessage trusts only type/messageId/readAt/actor fields; frames carry IDs not payloads; malformed JSON swallowed (no crash, no leak) |
| T-94-03 | Denial of service | reconnect loop | mitigate | capped exponential backoff (×2 to 30s) + destroyed-flag teardown prevent tight reconnect loops on persistent failure |
| T-94-04 | Tampering | Idempotency-Key on send | mitigate | per-send unique key forwarded as header; backend verify_client_idempotency dedupes (Phase 90) |
| T-94-SC | Tampering | npm installs | mitigate | No new packages installed in this plan (reuses existing deps); slopcheck N/A |
</threat_model>
