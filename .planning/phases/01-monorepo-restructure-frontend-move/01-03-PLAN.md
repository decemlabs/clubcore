   pnpm install

Pre-check: confirm port 5173 is free. If a previous run left a dev server alive, reap it first.

```bash

```

Start the dev server in the background, capturing its PID and logs:

```bash
mkdir -p .gsd-tmp
pnpm --filter sportzal-adminka dev > .gsd-tmp/admin-web-dev.log 2>&1 &
DEV_PID=$!
echo "$DEV_PID" > .gsd-tmp/admin-web-dev.pid
```

Wait for the server to become ready. Vite typically binds within 1–3 seconds on a warm node_modules; allow up to 30 seconds with a polling probe (do NOT use a long blocking sleep — per get-shit-done conventions, poll until the condition holds):

```bash
for i in $(seq 1 30); do
  if curl -fsS -o /dev/null http://localhost:5173/; then
    echo "Vite ready after ${i}s"
    break
  fi
  sleep 1
done
```

Probe the SPA shell:

```bash
RESPONSE=$(curl -fsS http://localhost:5173/)
echo "$RESPONSE" | grep -q '<div id="root">' || { echo "FAIL: response does not contain <div id=\"root\">"; echo "$RESPONSE" | head -40; exit 1; }
echo "PASS: SPA shell served with <div id=\"root\">"
```

The grep target `<div id="root">` is what the moved `apps/admin-web/index.html` actually renders (verified by reading the file — it is the SPA mount node).

Stop the dev server:

```bash
DEV_PID=$(cat .gsd-tmp/admin-web-dev.pid 2>/dev/null)
if [ -n "$DEV_PID" ]; then
  kill "$DEV_PID" 2>/dev/null || true
  # Give Vite a moment to exit gracefully, then force-kill any survivors on 5173
  sleep 2
  lsof -ti tcp:5173 2>/dev/null | xargs -r kill -9 2>/dev/null || true
fi
rm -f .gsd-tmp/admin-web-dev.pid
```

Final check: port 5173 is free again.

```bash
! lsof -ti tcp:5173 >/dev/null 2>&1
```

Cleanup the temporary scratch directory so it does not pollute `git status` (W5):

```bash
rm -rf .gsd-tmp
```
