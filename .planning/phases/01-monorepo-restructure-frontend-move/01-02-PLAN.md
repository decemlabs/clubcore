Step 1 — create the destination:

Step 2 — pre-emptively remove build artifacts and the foreign dependency tree from the source so they are NOT moved (per D-05 exclusions: `.git` already gone, plus `node_modules`, `dist`, `.tanstack`; also drop `.DS_Store`):

Step 3 — move every remaining top-level entry (regular files AND dotfiles) from `frontend/` into `apps/admin-web/`. The shell glob `frontend/{*,.[!.]*,..?*}` covers normal files, dotfiles starting with a single dot, and entries starting with `..` while excluding `.` and `..` themselves. Use `mv -n` (no clobber) to fail loudly if a destination file exists from any prior partial run:

```bash
shopt -s dotglob nullglob 2>/dev/null || true
for entry in frontend/* frontend/.[!.]* frontend/..?*; do
  [ -e "$entry" ] || continue
  mv -n "$entry" apps/admin-web/
done
```

If your shell does not support `dotglob` (e.g. plain `sh`), an equivalent that is portable on macOS/Linux:

```bash
( cd frontend && for entry in * .[!.]* ..?*; do
    [ -e "$entry" ] || [ -L "$entry" ] || continue
    mv -n "$entry" ../apps/admin-web/
  done )
```

Step 4 — remove the now-empty `frontend/` directory:

```bash
rmdir frontend
```

If `rmdir frontend` fails because something remains, list the residue (`ls -A frontend`) and stop — DO NOT `rm -rf frontend` blindly; investigate the leftover entry first. Acceptable residue is zero entries; anything else is a planning bug.
