## Deviations from Plan

### Rule 4 — Architectural (User-Approved 2026-04-30)

**[Rule 4] Added `eslint-import-resolver-typescript` to `apps/admin-web/package.json` devDependencies**

- **Found during:** Task 2 (first executor session), running `pnpm --filter sportzal-adminka lint`.
- **Symptom:** 52 errors of the form `Resolve error: typescript with invalid interface loaded as resolver  import/no-restricted-paths`, one per source file with imports. Lint exited 1.
- **Root cause:** `apps/admin-web/eslint.config.js` lines 41-44 declare `'import/resolver': { typescript: true, node: true }`, which requires `eslint-import-resolver-typescript` at runtime. The package was never declared in `apps/admin-web/devDependencies`. Under pnpm 9 workspace strict-install (no auto-hoisting of optional peers), the resolver was absent from `node_modules`. This is a **pre-existing latent bug** in the original `frontend/package.json`, exposed by the workspace move because the legacy install pathway happened to leave the resolver on disk via different means.
- **Locked-decision conflict:**
  - **D-04** (verbatim move of `apps/admin-web/package.json`) — forbids the manifest edit.
  - **D-14** (zero edits inside `apps/admin-web/`; root-level edits permitted only when justified) — same.
  - **D-07** (test files unmodified) — applied here in spirit.
  - **D-16** (must-have: `lint` exits 0) — demands the lint gate pass.
  - ROADMAP Phase 1 success criterion #4 (`pnpm --filter admin-web lint` succeeds) — same.
- **Why Rule 4 (not Rules 1-3):** D-04/D-14 vs D-16 are **both user-locked**, so resolving the conflict required a user decision. The first executor session correctly stopped and presented three options.
- **User decision (LOCKED 2026-04-30 via `/gsd-execute-phase` checkpoint):** Apply Option 1 — add the missing devDep. This relaxes D-04/D-14 minimally (one-line manifest edit, no source changes) to honor D-16 and the underlying ROADMAP success criterion.
- **Justification accepted:** This is mechanically the smallest possible fix; it closes a pre-existing latent bug; it preserves the spirit of D-04/D-14 (no source edits, no semantic config changes); and it ensures D-16 is met in the literal form the user demanded.
- **Fix applied:**
  ```diff
    "devDependencies": {
      ...
      "eslint": "^9.17.0",
  +   "eslint-import-resolver-typescript": "^3.6.3",
      "eslint-plugin-import": "^2.32.0",
      ...
    }
  ```
  Followed by `pnpm install` (added 11 packages including the resolver and its transitive deps). Lockfile delta is purely additive — no version bumps or removals.
- **Files modified:** `apps/admin-web/package.json`, `pnpm-lock.yaml`
