Seed pattern:

```python
from datetime import datetime, timedelta, timezone
from uuid import uuid4
import hashlib

def _seed_token(session, user_id, *, expires_offset_days):
    raw = uuid4().hex
    return PasswordResetToken(
        user_id=user_id,
        token_hash=hashlib.sha256(raw.encode()).hexdigest(),
        purpose="password_reset",
        expires_at=datetime.now(timezone.utc) + timedelta(days=expires_offset_days),
        audit_correlation_id=uuid4(),
    )
```

For the deleted-side fixtures: `expires_offset_days = -31` (32 days past expiry — outside 30d retention).
For the preserved-side fixtures: `expires_offset_days = -29` (29 days past expiry — within retention) AND `expires_offset_days = +1` (still valid).
