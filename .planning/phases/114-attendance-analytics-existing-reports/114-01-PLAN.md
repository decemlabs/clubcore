  <behavior>
    deriveDayOfWeek(daily):
    - Returns exactly 7 buckets in Mon-first order (Пн, Вт, Ср, Чт, Пт, Сб, Вс).
    - Empty / all-zero daily → 7 buckets, each total=0, daysWithData=0, avgPerWeekday=0, NO NaN.
    - Weekday index computed MSK-safe: parseISO(bucket.date) then (getDay()+6)%7 so Mon=0…Sun=6.
    - '2024-01-15' (a Monday) maps to the Пн bucket (index 0).
    - avgPerWeekday = daysWithData === 0 ? 0 : total / daysWithData (divide guarded).
    derivePeakHour(hourly):
    - All counts 0 (or empty) → null.
    - Single non-zero hour → returns { hour, count } for that hour.
    - Tie (two equal maxima) → returns the EARLIER hour.
    deriveFrequency(daily):
    - Returns 6 fixed buckets labeled '0–4','5–9','10–14','15–19','20–24','25+' in that order.
    - Empty daily → all 6 buckets count=0.
    - A day with daily.count=3 lands in '0–4'; count=25 and count=99 both land in '25+'.
  </behavior>
