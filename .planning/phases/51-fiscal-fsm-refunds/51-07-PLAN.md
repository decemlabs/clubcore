<objective>
Ship the three new ЮKassa webhook handlers (`handle_refund_succeeded`, `handle_receipt_succeeded`, `handle_receipt_canceled`) AND extend the event-dispatch chain in router.py to route the three new event types to them. This is the half of Phase 51 that turns inbound ЮKassa state-change events into atomic DB writes.

**Three handlers, three different shapes:**

1. **`handle_refund_succeeded`** — the heavy one. Atomic UoW that simultaneously:
   - UPDATEs `online_refunds.status='succeeded'`,
   - INSERTs a signed-negative refund row in `payments` via the `PaymentRefunder` Protocol slot (catching IntegrityError on `uq_payments_refund_of_alive` for REFUND-03 idempotent semantics),
   - Calls `repository.update_membership_status` (or pt_package equivalent) **directly** with `CANCELLATION_REASON_REFUNDED` (NOT via activator — D-51-11 / errata #4 — activators are forward-only),
   - INSERTs `fiscal_receipts(kind='refund', status='sent')`,
   - Emits 3 child audit events + 1 root `yookassa_webhook_received` event,
   - And does so AFTER re-fetching the refund via `get_refund(object_id)` per the D-50-12 financial-state-change-requires-re-read doctrine.

2. **`handle_receipt_succeeded`** — light. SELECT-FOR-UPDATE the FiscalReceipt row by `yookassa_receipt_id`, FSM-guard `_assert_can_transition_receipt(target='succeeded')`, UPDATE `status='succeeded'` + `succeeded_at=now(UTC)`, emit `fiscal_receipt_succeeded` audit + `yookassa_webhook_received` root. **No re-fetch** (D-51-03 — receipt status is informational, no money moves).

3. **`handle_receipt_canceled`** — mirror of handle_receipt_succeeded with `target='failed'`, `failed_at=now(UTC)`, `failure_reason` extracted from `body["object"]["cancellation_details"]["reason"]`, emits `fiscal_receipt_failed` audit.

Plus the router.py extension: three new `elif event_type == ...` branches that dispatch to these handlers.

Output: 2 modified files + 3 new test files covering each handler's success path, FSM-guard rejection path, idempotent-replay path, and orphan-row path.
</objective>

async def handle_receipt_succeeded(

    *,
    body: dict[str, Any],
