# Phase 22 — UI Design Contract

> Visual and interaction contract for admin-web Phase 22 surfaces: /clients/$clientId (Pattern α), /memberships, /membership-plans, /visits (check-in), sidebar extension, ClientsTable row navigation, active-sessions UI (FE-09 sub-plan). Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn |
| Preset | base-nova, neutral base color, cssVariables: true (detected from `apps/admin-web/components.json`) |
| Component library | Radix UI (via shadcn primitives) + `@reui` registry at `https://reui.io/r/{style}/{name}.json` |
| Icon library | lucide-react 0.469.0 |
| Font | System font stack (no custom webfont declared in `index.css`) |

**Registry safety gate:** The `@reui` registry is an existing project dependency declared in `components.json` and is already in use across `src/shared/ui/`. It is not a new third-party addition introduced by Phase 22. No new third-party registries are introduced in this phase. Phase 22 uses only shadcn official components from the existing `src/shared/ui/` inventory and lucide-react icons already present in the project.

## Spacing Scale

All values from Tailwind's default 4px-base scale consumed via Tailwind utility classes. shadcn `<Card>` and `<Dialog>` components carry their own internal padding; the values below govern Phase 22 composition-level spacing between elements.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (`gap-1`, `p-1`) | Icon gaps, inline badge padding |
| sm | 8px (`gap-2`, `p-2`) | Compact row spacing, button icon gap |
| md | 16px (`gap-4`, `p-4`) | Default element spacing, card body padding |
| lg | 24px (`gap-6`, `p-6`) | Section padding inside cards (mirrors existing `<Card>` anatomy) |
| xl | 32px (`gap-8`) | Gap between stacked blocks on `/clients/$clientId` Pattern α layout |
| 2xl | 48px (`gap-12`) | Not used directly; reserved for future page-level major breaks |
| 3xl | 64px | Not used in Phase 22 |

Exceptions:

- Touch targets for action icon buttons: 36px (`h-9 w-9`) — matches `ClientsTable` precedent (`h-9 w-9` on Pencil/Trash2 buttons).
- Disambiguation list on `/visits` check-in page: `py-3 px-4` per row (12px vertical, 16px horizontal) so the 5-item list is comfortable to tap on a reception tablet.

- `<Badge>` text: inherits shadcn Badge default (`text-xs font-medium`).

## Color

All colors are semantic shadcn tokens only. Raw palette classes are ESLint-banned.

| Role | Token | Usage |
|------|-------|-------|
| Dominant (60%) | `bg-background` | Page background |
| Secondary (30%) | `bg-card` / `bg-sidebar` | Cards (`<MembershipsBlock>`, `<RecentVisitsBlock>`, `<ClientProfileCard>`), sidebar |
| Accent (10%) | `bg-primary` / `text-primary` | Reserved for: active sidebar item indicator, primary CTA buttons ("Продать абонемент", "Отметить"), focused form ring |
| Destructive | `bg-destructive` / `text-destructive` | D-3 "истёк сегодня" badge (`<Badge variant="destructive">`), Cancel membership button (`text-destructive`), delete confirmations |
| Success (extra token) | `bg-success` / `text-success-foreground` | Defaulted (auto-mode) — "Отмечен сегодня" status indicator on check-in disambiguation list; available via `--color-success` / `--color-success-foreground` reui extras already in `index.css` |
| Muted | `text-muted-foreground` | Secondary metadata, empty state body text, disabled button labels |
| Border | `border-border` | Card borders, table dividers, input outlines |

Accent reserved for: active sidebar nav item, primary action buttons (sell membership, check-in), form focus ring. NOT used for status labels, metadata, or decorative elements.

Dark mode: all semantic tokens resolve automatically via the `.dark` block in `index.css`. No Phase 22 component uses raw palette values — parity is automatic.

### 2. ClientsTable Row Navigation (D-22-5)

**Source:** CONTEXT.md D-22-5 (locked)

Each data row in `<ClientsTable>` becomes navigable to `/clients/$clientId`.

Implementation contract:
- Wrap the row `<tr>` with a TanStack Router `<Link to="/clients/$clientId" params={{ clientId: row.original.id }}>` OR use `useNavigate` in `onRowClick`.
- Row cursor: `cursor-pointer hover:bg-muted/50` (matches shadcn table row hover token).
- Inline edit (Pencil) and delete (Trash2) `<Button>` handlers call `event.stopPropagation()` before invoking `onEdit` / `onDelete`. They must NOT trigger row navigation.
- `aria-label` on the clickable row or a visually hidden text: "Открыть профиль клиента {fullName}" — Defaulted (auto-mode): use `title` attribute on the row link for brevity.

### 3. `/clients/$clientId` — Pattern α Stacked Blocks (D-22-6)

**Source:** CONTEXT.md D-22-6 (locked)

- Empty state: "Посещений нет" centered text.

### 9. D-3 Badge — "истёк сегодня" (D-22-9)

**Source:** CONTEXT.md D-22-9 (locked)

Trigger condition: `endDate === todayMSK() && status === 'active'` on a membership row inside `<MembershipsBlock>`.

`todayMSK()` helper: not present in `src/shared/i18n/date.ts` (verified — file exports `formatDate`, `formatTime`, `formatDateTime`, `formatDate` — no `todayMSK`). Must be added to `src/shared/i18n/date.ts`:
```ts
// Returns today's date in YYYY-MM-DD format pinned to Europe/Moscow timezone
export function todayMSK(): string {
  return new Intl.DateTimeFormat('sv-SE', { timeZone: MOSCOW_TZ }).format(new Date())
}
```
(The `sv-SE` locale produces ISO `YYYY-MM-DD` format — Defaulted auto-mode standard pattern for TZ-safe today.)

Rendered component: `<Badge variant="destructive" className="ml-2 text-xs">истёк сегодня</Badge>` inline next to the period column's end-date text.

## Accessibility

| Requirement | Implementation |
|-------------|----------------|
| Keyboard navigation | All interactive elements are natively focusable (`<button>`, `<a>`, `<input>`, `<select>`). Dialog focus trapping provided by Radix UI Dialog primitives. |
| Screen reader labels | Disabled "Отметить" button must have `aria-disabled="true"` AND descriptive `aria-describedby` pointing to the reason text (outside hours / already checked in). Icon-only buttons must have `aria-label` in Russian. |
| Color contrast | Semantic tokens meet WCAG AA by shadcn design. `text-destructive-foreground` on `bg-destructive` is verified in both light and dark modes by the theme values in `index.css`. |
| Focus ring | Global `outline-ring/50` applied via `@layer base` in `index.css`. No overrides needed. |
| Role gate visibility | Hidden (not `display:none` with CSS but conditionally rendered in JSX via `<RoleGate>`) — reception does not see the cancel button DOM node at all. |
| Empty states | Each empty state has a semantic `<h2>` heading + `<p>` body for screen reader context. |
| Disambiguation list | Use `role="listbox"` and `role="option"` on the phone-search disambiguation list so screen readers announce the selection context (Defaulted auto-mode). |
