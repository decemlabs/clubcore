<decisions>
## Implementation Decisions

### Contract test — REAL backend response (criterion #2)
- **Mechanism (FE Zod × captured JSON):** a backend ASGITransport test per new domain hits the REAL
  endpoint, serializes the actual JSON response into a SHARED fixtures directory (the snapshot is
  GENERATED by the test from the live ASGITransport call — never hand-authored). An FE vitest contract
  test then loads that captured JSON and parses it with the domain's REAL FE Zod schema, asserting it
  passes. This closes the loop FE Zod ↔ real backend JSON end-to-end.
- **Domains (≥1 each):** refund, role-change, promo, analytics/LiveNow (cohort/anomaly/at-risk/load-now),
  staff-messages. (The CSV payments export is asserted at the backend tier — BOM/headers — since it's
  not a Zod-parsed JSON body.)
- **"not a mock fixture":** the captured JSON is the serialized real ASGITransport response, committed
  as a snapshot; FE contract tests live next to their feature (`features/<domain>/*.contract.test.ts`)
  and load the shared snapshot.

### OpenAPI regen + `_v32Checks` guard + gate (criterion #1, #3)
- **Regen flow:** `cd apps/backend && uv run python -m scripts.export_openapi` (dumps openapi.json
  byte-stably via `create_app().openapi()`), then `pnpm -F @clubcore/api-client codegen`
  (openapi-typescript → `src/schema.d.ts`). ADDITIVE (not byte-stable — new paths appear). Remove the
  temporary `as unknown as keyof paths` / stub `schema.d.ts` path entries added in phases 113/115/116
  now that the real types exist.
- **`_v32Checks`:** extend `packages/api-client/src/schema.contract.test.ts` with an `AssertNonNever`
  tuple per NEW v3.2 path×method (refund, role, promo CRUD ×5, cohort/anomaly/at-risk/load-now,
  messages threads/{id}/reply/read, payments.csv) — plus body + 2xx realisation probes where applicable.
- **Milestone gate (must be GREEN, fix-to-green within this phase):**
  - Backend: `uv run mypy app` (--strict), `uv run lint-imports`, `uv run ruff check`, `uv run pytest`
    (full suite).
  - Frontend: `pnpm -F @clubcore/admin-app check` (typecheck+lint), `test`, `build`;
    `pnpm -F @clubcore/api-client typecheck` + `test` (contract guard) + `codegen` clean.
  - Redocly lint on openapi.json (if configured).
  - CISO-01 RBAC byte-parity guard green (backend↔FE OWNER_ONLY parity — now 46 entries).
  - All 13 v3.2 requirements (REF-01, TEAM-01, PROMO-01/02, ANL-01/02/03/04, MSG-01/02, EXP-01/02,
    HND-01) traced as satisfied.
- **If the gate fails:** fix to green within this phase — a green gate IS the milestone exit criterion.
