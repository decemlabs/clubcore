```python
async def get_plan_for_renewal(
    session: AsyncSession,
    plan_id: UUID,
) -> tuple[MembershipPlan | None, bool]:
    """Read plan ignoring soft-delete; return (plan, is_archived) for renewal classification (Phase 26 D-26-08).

    Phase 26 needs to discriminate "plan never existed" (404 plan_not_found)
    from "plan exists but archived" (409 plan_archived). `get_alive` collapses
    both to None, so renewal uses this helper instead. NO other caller should
    use this — bypassing soft-delete in any other write path is a bug.
    """
    stmt: Select[tuple[MembershipPlan]] = select(MembershipPlan).where(
        MembershipPlan.id == plan_id,
    )
    plan: MembershipPlan | None = await session.scalar(stmt)
    if plan is None:
        return (None, False)
    return (plan, plan.deleted_at is not None)
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → POST `/memberships/{id}/renew` | Untrusted reception/owner request must be authenticated, CSRF-checked, and authorised before any DB mutation |
| Operator → renewal of cancelled membership | Cancelled is terminal/intentional; renewal-as-workaround would silently undo cancellation |
| Operator → renewal of archived plan | Archived plan represents owner's "stop selling this" intent; renewing against it bypasses that intent |
| Service → audit emit | The `membership_renewed` event MUST fire exactly once per successful renewal; payload must capture price-at-time-of-renewal for revenue forensics |
| Repository → insert_renewal_membership | Snapshots MUST come from CURRENT plan, not source's stale snapshots, or the "if plan got more expensive, client pays new price" lock breaks |
