## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gap from label in amenity cell |
| sm | 8px | Row internal gap (icon + text); group label bottom margin |
| md | 16px | Sheet horizontal padding; card internal padding |
| lg | 24px | Section vertical gap between groups |
| xl | 32px | Bottom safe-area padding |
| 2xl | 48px | Empty / error state vertical centering offset |
| 3xl | 64px | Not used in this sheet |

Exceptions:

- Sheet entry animation uses `position: absolute; inset: 0; z-index: 220` — no spacing exception, but z-index matches existing sub-sheet pattern (BonusHistorySheet, CardSheet).

- Photo strip cells: `height: 80px; border-radius: var(--r-lg)` — decorative, not tied to spacing scale.
- Hairline dividers between list rows: `height: 0.5px; background: var(--border); marginLeft: 44` — matches BonusRow / Divider3 pattern.

## Layout: GymInfoSheet Structure

The sheet is a **full-screen sub-sheet** (z-index 220, `sheet-up` animation, `position: absolute; inset: 0`). It is read-only — no user input, no mutations.

### Visual Sections (top to bottom)

```
StatusBar
SubSheetHeader ("Информация о зале")
─── .scroller ───────────────────────────────────
  [1] HERO CARD               — name, tagline, address, metro
  [2] PHOTO STRIP             — horizontal scroll, 5 decorative cells (frontend-only static)
  [3] HOURS SECTION           — section label + card: today row + open/closed badge + weekly table
  [4] AMENITIES GRID          — section label + card: 4-col icon grid (8 items)
  [5] RULES LIST              — section label + card: numbered list (5 rules)
  [6] CONTACTS SECTION        — section label + card: phone row + email row
  [7] SOCIAL LINKS            — section label + card: tg row + ig row (rendered only if present)
  [bottom padding: 32px]
─────────────────────────────────────────────────
```

### [1] Hero Card

Container: `.card` with `padding: 16px; margin: 8px 16px 0`.

- Row 1: Gym name — `.t-h2` color `var(--text)`
- Row 2: Tagline — `.t-body` color `var(--text-2)`
- Row 3 (gap 8px below tagline): address chip — `<span className="chip">` with `mapPin` icon (16px) + address text
- Row 4 (gap 4px): metro chip — `<span className="chip">` with `navigation` icon (16px) + metro text

### [2] Photo Strip

Container: `padding: 12px 0 4px; overflow-x: auto; scrollbar-width: none` — horizontal scroll, no scroll bar shown.
Inner: `display: flex; gap: 8px; padding: 0 16px`.

Each cell: `width: 88px; height: 80px; border-radius: var(--r-lg); flex-shrink: 0; background: {bg from static data}; display: flex; flex-direction: column; align-items: center; justify-content: center; gap: 4px`.
- Icon: `<Icon name={icon} size={20} color="rgba(255,255,255,0.85)" />`
- Tag label: `font-size: 11px; font-weight: 600; color: rgba(255,255,255,0.85); letter-spacing: 0.3px`

Photo data is **frontend-only static** (not from API). Uses the `photos` array from the original `gym.js` shape. Not migrated to backend (per CONTEXT.md decision).

### [3] Hours Section

Section label: `.t-mini` `padding: '16px 16px 8px'` → "ЧАСЫ РАБОТЫ"

Container: `.card padding: 0 margin: 0 16px 0 overflow: hidden`

**Today row** (always first, visually highlighted):
- Left: day abbrev (`.t-h3` 14px) + "сегодня" hint (`.t-small` color `var(--text-3)`)
- Right: "HH:MM – HH:MM" (`.t-body` font-variant-numeric tabular-nums) + open/closed badge

**Open/Closed badge derivation rule** (client-side, not stored in DB):
```
const now = new Date(new Intl.DateTimeFormat('en', {timeZone:'Europe/Moscow',...}).format())
const todayRow = hours[todayIdx]   // todayIdx = (now.getDay() + 6) % 7 (Mon=0 … Sun=6)
const nowMinutes = now.getHours() * 60 + now.getMinutes()
const openMinutes = parseHHMM(todayRow.open)
const closeMinutes = parseHHMM(todayRow.close)
const isOpen = nowMinutes >= openMinutes && nowMinutes < closeMinutes
```
- If `isOpen`: render `<span className="chip chip-accent">Сейчас открыто</span>` + secondary line `.t-small` "до HH:MM"
- If `!isOpen`: render `<span className="chip chip-danger">Закрыто</span>` + secondary line `.t-small` "откроется в HH:MM" (next open time; show tomorrow's time if today's open hasn't started yet, or if closed for the night)

`.chip-danger`: `background: var(--danger-soft); color: var(--danger); border-color: transparent; font-weight: 600` — matches existing `.chip-danger` CSS class.

Hairline divider (`height: 0.5px; background: var(--border)`) after today row.

**Weekly table** (remaining 6 days below divider, in order after today):
Each row: `padding: 12px 14px; display: flex; align-items: center; gap: 12`.
- Left: day abbrev `.t-small` `width: 28px; color: var(--text-2)`
- Right: "HH:MM – HH:MM" `.t-small font-variant-numeric tabular-nums color: var(--text)`
- No badge on non-today rows.
- Hairline divider between rows (`marginLeft: 42`).

### [4] Amenities Grid

Section label: `.t-mini` `padding: '16px 16px 8px'` → "УДОБСТВА"

Container: `.card padding: 12px margin: 0 16px 0`

- Icon: `<Icon name={amenity.icon} size={16} color="var(--accent-deep)" />`
- Label: `font-size: 11px; font-weight: 600; color: var(--text-2); text-align: center; line-height: 1.2`

Icon name mapping (all icons already exist in `Icon.jsx`):

|---|---|
| parking | parking |

| shower | shower |
| locker | locker |

### [5] Rules List

Section label: `.t-mini` `padding: '16px 16px 8px'` → "ПРАВИЛА"

Container: `.card padding: 0 margin: 0 16px 0 overflow: hidden`

Each rule row: `padding: 12px 14px; display: flex; align-items: flex-start; gap: 12`
- Number circle: `width: 22px; height: 22px; border-radius: 999px; flex-shrink: 0; background: var(--surface-2); border: 0.5px solid var(--border); display: flex; align-items: center; justify-content: center; font-size: 11px; font-weight: 700; color: var(--text-3)`
- Rule text: `.t-body` `flex: 1; line-height: 1.5; color: var(--text)`

Hairline divider (`height: 0.5px; background: var(--border); marginLeft: 46`) between rule rows.

### [6] Contacts Section

Section label: `.t-mini` `padding: '16px 16px 8px'` → "КОНТАКТЫ"

Container: `.card padding: 0 margin: 0 16px 0`

Phone row: `<a href="tel:{phone}">` — tappable, triggers native dialer.
Email row: `<a href="mailto:{email}">` — tappable, triggers mail client.

Each row pattern: `padding: 14px 14px; display: flex; align-items: center; gap: 12; text-decoration: none; color: inherit`
- Icon container: `width: 32px; height: 32px; border-radius: 8px; background: var(--surface-2); display: flex; align-items: center; justify-content: center`
  - Phone: `<Icon name="phone" size={16} color="var(--text-2)" />`
  - Email: `<Icon name="mail" size={16} color="var(--text-2)" />`
- Content: `flex: 1`
  - Primary: `.t-h3` 14px — display value (formatted phone / email address)
  - Secondary: `.t-small` color `var(--text-3)` — "Позвонить" / "Написать"
- Trailing: `<Icon name="chevronRight" size={16} color="var(--text-3)" />`

Hairline divider between phone and email rows.

### [7] Social Links (conditional)

Rendered only if `data.social && data.social.length > 0`.

Section label: `.t-mini` `padding: '16px 16px 8px'` → "МЫ В СОЦСЕТЯХ"

Container: `.card padding: 0 margin: 0 16px 0`

Each social row: `<a href={socialUrl(item)} target="_blank" rel="noopener noreferrer" ...>`
- Pattern identical to contacts rows (icon container + primary + trailing chevron).
- `tg` → `<Icon name="telegram" size={16} />` + label "Telegram" + handle as secondary
- `ig` → `<Icon name="instagram" size={16} />` + label "Instagram" + handle as secondary

Social URL derivation (client-side):
- `tg`: `https://t.me/{handle.replace('@','')}` 
- `ig`: `https://instagram.com/{handle.replace('@','')}`

## Loading State

Pattern: query skeleton matching BonusHistorySheet / CardSheet conventions.

While `isLoading`:
- Hero card area: two `.sk.sk-line` blocks (widths 60%, 40%) + two `.chip` skeleton chips side by side
- Hours section: `.card` with four `.sk.sk-line` (widths 80%, 60%, 70%, 55%, margin-bottom 12px between)
- Amenities grid: 8 skeleton circles — `width: 32px; height: 32px; border-radius: 8px` with `.sk` pulsing animation
- Photo strip: 5 skeleton cells `width: 88px; height: 80px; border-radius: var(--r-lg)` with `.sk`
- Rules / contacts / social sections: 3 `.sk.sk-line` each in a `.card` container

All skeleton containers maintain the same structural padding/margins as their loaded equivalents, preventing layout shift.

---

## Error State

Inline error within the sheet (not a full-screen error — the sheet stays open with `SubSheetHeader` visible so the user can close it).

Visual: Centered in the content area, `padding: 40px 24px; text-align: center`.

```
[alertCircle icon — 40px — in danger-soft circle 64px]
[gap 16px]
[t-h3 "Не удалось загрузить информацию о зале"]
[gap 8px]
[t-small color var(--text-2) "Потяните вниз, чтобы попробовать снова."]
```

Pull-to-refresh (`<PullToRefresh>`) wraps the scroller content, consistent with BonusHistorySheet.

On refresh — re-triggers the query; skeleton replaces error content during re-fetch.

## Empty State

Not applicable for GymInfoSheet — the gym record is always seeded by migration (GYM-03). If the API returns a 404 (seed missing), treat as error state.

## Interaction Contract

| Interaction | Behavior |
|-------------|----------|
| Phone row tap | `window.location.href = 'tel:{phone}'` — triggers native dialer |
| Email row tap | `window.location.href = 'mailto:{email}'` — triggers mail client |
| Social row tap | `window.open(url, '_blank', 'noopener,noreferrer')` |
| Pull-to-refresh | Calls `refetch()` on the gym query; shows loading state |
| Close (chevronLeft) | Calls `onClose()` prop — matches SubSheetHeader pattern |
| Photo strip swipe | Native horizontal scroll — no JS handler needed |

No editable fields. No mutations. No optimistic updates. Sheet is read-only.
