### Gaps Detail

**Gap: Mock list() missing status filter (SC #3 partial)**

SC #3 requires "mock service синхронизирован". The mock service implements:
- Frozen badge rendering — YES (StatusBadge used in list and block; frozen memberships display correctly)
- freeze/unfreeze/renew operations — YES (full parity tests in memberships.freeze.test.ts and memberships.renew.test.ts)
- Frozen filter pill navigation — PARTIAL (pill sets `?status=frozen` in URL but mock ignores `query.status`)

Root cause: CONTEXT.md D-28-11 incorrectly stated "Mock + http already accept any MembershipStatus via the `status?` query param." Git history confirms mock list() never filtered by status (unchanged since commit 7a7bcda / Phase 22). Phase 28-07 wave added the frozen pill UI and MembershipsBlock badge but did not add the corresponding mock filter.

Impact: In VITE_API_MODE=mock, the "Заморожен" filter pill is a no-op — returns all memberships instead of frozen-only. VITE_API_MODE=http works correctly.

Fix is a one-liner: `if (query.status) { all = all.filter((m) => m.status === query.status) }` after line 36 in mock/memberships.ts.

### Gaps Summary

**1 gap blocking full SC #3 achievement:**

The mock service `list()` does not filter by `query.status`. When a developer uses `VITE_API_MODE=mock` and clicks the "Заморожен" filter pill, the URL becomes `?status=frozen` but the mock returns the entire membership list unfiltered. HTTP mode works correctly. This violates the "mock service синхронизирован" requirement in SC #3 and the FE-11 acceptance criterion.

**Root cause:** CONTEXT.md D-28-11 incorrectly assumed mock already supported status filtering. Git history confirms this was never implemented (absent from commit 7a7bcda through all Phase 28 commits).

**Fix (minimal):** In `apps/admin-web/src/shared/api/services/mock/memberships.ts`, `list()` function, after line 36 (`if (query.clientId)`), add:
```typescript
if (query.status) {
  all = all.filter((m) => m.status === query.status)
}
```
Also add a parity test verifying `list({ page:1, pageSize:20, status:'frozen' })` returns only frozen memberships.
