## Spacing Scale

8-point scale (multiples of 4). All values are applied via Tailwind semantic spacing utilities; raw pixel values are listed for clarity.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, tab indicator thickness, inline badge padding |
| sm | 8px | Input internal padding (vertical), DataGrid cell padding, form field gaps |
| md | 16px | Card padding, Dialog body padding, form section gaps, toolbar item spacing |
| lg | 24px | Dialog header/footer padding, page section breaks, login card vertical rhythm |
| xl | 32px | Login card max-width internal padding, DataGrid toolbar-to-table gap |
| 2xl | 48px | Login page vertical centering offset, splash screen logo-to-spinner gap |
| 3xl | 64px | Login card max-width constraint side margins (below xl breakpoint) |

Exceptions:
- Touch targets (row action buttons, icon-only buttons): minimum 44px height — use `h-11` (44px) per WCAG 2.5.5
- InputOTP digit cells: 48px width × 56px height — ReUI default, do not override
- Telegram poll countdown badge: 4px padding (xs) — compact inline status indicator

## Typography

All type is rendered in Russian. Font stack is system sans-serif inherited from shadcn base.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px (text-sm) | 400 (regular) | 1.5 | DataGrid cell text, form helper text, dialog body, ProfileMenu items, sidebar labels |
| Label | 14px (text-sm) | 400 (regular) | 1.4 | Form field labels, tab labels, column headers, toolbar button text |
| Heading | 20px (text-xl) | 600 (semibold) | 1.2 | Dialog titles, page heading ("Клиенты"), login card heading ("Войти в систему") |
| Display | 28px (text-3xl) | 600 (semibold) | 1.1 | Splash screen logo text only — one instance total |

**Constraints:**
- Exactly 4 sizes declared; no intermediate sizes (text-base, text-lg, text-2xl) in Phase 10 surfaces.
- Exactly 2 weights: 400 (regular) for body and label roles; 600 (semibold) for heading and display roles. No 500 (medium) or 700 (bold).
- Monospace for InputOTP digit cells: system monospace (`font-mono`) at 20px / weight 600 — ensures digit alignment.

## Color

All colors use semantic shadcn CSS custom property tokens. Raw palette classes (`bg-zinc-900`, `text-slate-500`) are banned by ESLint. Light and dark theme values are already declared in `src/app/index.css`.

| Role | Token | Usage |
|------|-------|-------|
| Dominant (60%) | `bg-background` / `text-foreground` | Page backgrounds, login card background, splash screen |
| Secondary (30%) | `bg-card` / `bg-muted` / `bg-sidebar` | DataGrid row hover, form input backgrounds, dialog overlay backdrop, sidebar surface |
| Accent (10%) | `bg-primary` / `text-primary-foreground` | See reserved list below |
| Destructive | `bg-destructive` / `text-destructive-foreground` | Soft-delete confirm button in AlertDialog only |
| Success | `bg-success` / `text-success-foreground` | Telegram bound confirmation indicator (green dot + "Чат привязан") |
| Muted | `text-muted-foreground` | Helper text, placeholder text, secondary column data, poll timeout message |

**Accent (`bg-primary`) reserved for:**
1. Login submit button ("Войти") — primary action CTA only
2. "Новый клиент" button in clients toolbar — primary action CTA only
3. Confirm button in ClientForm Dialog save action ("Добавить клиента" / "Сохранить изменения")
4. Active tab indicator underline on Login tabs (email/password, Telegram)
5. Pagination "current page" active state

Accent is NOT used for: row hover, form focus rings (use `ring` token), status badges, informational text, navigation links, secondary actions.

**Focus ring:** `ring-ring` token, 2px offset — shadcn default, do not override.

## Interaction States

All interactive elements must implement the following states. Use shadcn/ReUI component variants — do not hand-roll.

| Element | States Required |
|---------|----------------|
| Button (primary) | default, hover, focus-visible, disabled, loading (spinner replaces icon) |
| Button (ghost/icon row action) | default, hover, focus-visible, disabled |
| Input / Form field | default, focus, error (destructive ring), disabled |
| InputOTP cell | default, active (current cell), filled, error |
| DataGrid row | default, hover (muted bg), selected (if applicable) |
| Tab trigger | inactive, active (primary underline), focus-visible |
| Dialog | closed, opening (fade+scale), open, closing |
| AlertDialog (delete confirm) | same as Dialog + destructive confirm button |
| Telegram status indicator | polling (animated pulse), bound (success dot), timed-out (muted) |
| Splash screen | visible (centered logo + spinner), fade-out on auth resolution |

## Component Behavior Contracts

### Login Form (Email/Password tab)

- `react-hook-form` + Zod schema; same schema used by `services.mock.auth`
- Email field: type=email, autocomplete=username
- Password field: type=password, autocomplete=current-password, show/hide toggle (Lucide `Eye`/`EyeOff`)
- On submit: button enters loading state (spinner, disabled); error appears inline below password field on 401; form re-enables on error
- On success: `router.navigate({to: search.next ?? '/', replace: true})`
- 429 response: show rate-limit message inline; form remains enabled (no lockout UI)

### Login Form (Telegram OTP tab)

- Step 1 (initial): "Получить ссылку Telegram" button visible; deep link URL not yet fetched
- Step 2 (polling): `useQuery({refetchInterval: 3000, enabled: !timedOut && !bound})`; animated pulse indicator "Ожидание подтверждения..."
- Step 3 (bound): polling stops; `InputOTP` (6 cells) appears; "Подтвердить код" button
- Step 4 (timed out after 5 minutes): `enabled=false`; muted message + "Получить новую ссылку" button
- Deep link displayed as clickable `<a target="_blank">` styled as button with Telegram icon (Lucide `MessageCircle` or equivalent)
- OTP error appears inline below InputOTP; cell border turns destructive

### DataGrid (Clients)

- Columns: ФИО (sortable), Телефон, Email (optional, truncated), Дата регистрации (sortable, format `dd.MM.yyyy`), Actions (right-aligned, not sortable)
- Default sort: `created_at DESC` (newest first)
- Row density: compact (ReUI DataGrid default density — do not override)
- No row selection checkboxes in Phase 10 (bulk actions deferred)
- Actions cell: edit action (Pencil icon, tooltip "Редактировать клиента") visible to all roles; `<RoleGate action="delete" resource="clients">` wrapping Trash2 icon button (tooltip "Удалить клиента") — reception gets no DOM node (D-11)
- Edit action opens Edit Dialog
- Sticky header: yes (DataGrid scroll area handles this)
- Virtualization: not required (~30 mock rows); DataGrid default behavior

### ClientForm Dialog

- Fields: Фамилия* (lastName), Имя* (firstName), Отчество (middleName), Телефон* (phone, masked `+7 (___) ___-__-__`), Email, Дата рождения (date input), Заметки (textarea)
- Required fields marked with `*` in label
- Phone field: masked input; if ReUI provides `PhoneInput`, use it; otherwise `react-imask` with mask `+{7} (000) 000-00-00` (Claude's discretion, not locked)
- Dialog width: `max-w-md` (448px)
- Submit button at Dialog footer, right-aligned; Cancel left-aligned
- Dirty-guard: if form is dirty and user clicks Cancel or backdrop, show no extra confirmation (Phase 10 scope — add dirty-guard in later phase if UX feedback demands)
- Create vs Edit: same `ClientForm` component, `mode` prop controls heading + submit label
- Submit label in create mode: "Добавить клиента"; submit label in edit mode: "Сохранить изменения"
- Cancel label: "Не сохранять" (in both create and edit mode)

### Delete Confirmation (AlertDialog)

- Triggered by Trash2 row action click
- Confirm button: `variant="destructive"` (red background)
- Cancel button: "Не удалять" — clearly non-destructive label
- On confirm: `useMutation` `onMutate` removes row from cached list optimistically; `onError` rolls back; `onSettled` invalidates `clientsKeys.lists()`
- Cancel restores normal state; no side effects

### ProfileMenu Logout

- Menu item: "Выйти" with Lucide `LogOut` icon
- No confirm dialog (D-08: logout is reversible)
- Handler sequence: `await services.auth.logout()` → `queryClient.clear()` → `router.navigate({to: '/login', replace: true})`
- Menu closes immediately on click; loading state on the menu item during logout call (spinner or disabled state on item)

### Splash Screen

- Renders when `main.tsx` is awaiting `ensureQueryData(authKeys.me)` in http-mode
- Layout: full viewport, centered content, `bg-background`
- Content: app logo/name (display 28px, weight 600) + loading spinner below (24px, `text-muted-foreground`)
- Spinner: Lucide `Loader2` with `animate-spin` class
- Duration: ~150-300ms RTT; no artificial minimum delay

### RoleSwitcher (mock-mode guard)

- `if (API_MODE !== 'mock') return null` — reception has no DOM node in http-mode
- Existing component; Phase 10 adds only the guard condition
