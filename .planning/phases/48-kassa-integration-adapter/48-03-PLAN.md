       ```
       async def build_yookassa_client(*, settings: YooKassaSettings) -> YooKassaClient:
           """Construct the process-wide YooKassaClient (D-48-06) + run non-fatal /v3/me probe (D-48-13..15).

           Divergence from email/factory.py:
             - httpx.AsyncClient is LONG-LIVED (factory returns a single instance per process,
               closed by FastAPI lifespan teardown / ARQ on_shutdown via client.aclose()).
             - Probe failure is NON-FATAL (D-48-14, SC2 — degraded mode). The constructed
               YooKassaClient is returned regardless; only the structlog signal differs.
             - Single probe attempt, no retry (D-48-15) — operator runbook covers degraded mode.

           The sandbox flag does NOT change the base URL (D-48-08); ЮKassa uses the SAME
           host with sandbox-issued credentials. `sandbox=True` only bypasses the
           webhook IP allowlist (Phase 47 D-47-07; Phase 48 webhook_verifier consumer).
           """
           http = httpx.AsyncClient(
               base_url=_YOOKASSA_BASE_URL,
               auth=httpx.BasicAuth(
                   username=str(settings.shop_id),
                   password=settings.secret_key.get_secret_value(),
               ),
               timeout=httpx.Timeout(connect=5.0, read=10.0, write=5.0, pool=5.0),
               headers={"User-Agent": "Sportzal/1.7 ЮKassa-Adapter"},
           )
           # D-48-13: boot probe via GET /v3/me. D-48-15: single attempt, no retry.
           try:
               resp = await http.get("me", timeout=5.0)
               resp.raise_for_status()
               body = resp.json()
               probe_account_id = body.get("account_id") if isinstance(body, dict) else None
               if probe_account_id is not None and str(probe_account_id) != str(settings.shop_id):
                   _log.warning(
                       "yookassa_boot_probe",
                       ok=False,
                       reason="shop_id_mismatch",
                       expected=str(settings.shop_id),
                       got=str(probe_account_id),
                   )
               else:
                   _log.info(
                       "yookassa_boot_probe",
                       ok=True,
                       shop_id=str(settings.shop_id),
                   )
           except Exception as exc:
               # D-48-14: NON-FATAL — log + continue. Caller still receives a usable client.
               _log.warning(
                   "yookassa_boot_probe",
                   ok=False,
                   reason=type(exc).__name__,
                   error=str(exc),
               )
           return YooKassaClient(http=http, settings=settings)
       ```

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-48-03-01 | Information Disclosure | secret_key in BasicAuth construction | mitigate | `secret_key.get_secret_value()` appears ONLY inside `httpx.BasicAuth(...)` — the auth object stores it internally and httpx serializes to `Authorization` header (HTTPS). The raw value is never logged, never in URL. Acceptance criterion: `! grep -q 'secret_key.*log\|_log.*secret_key' factory.py` (defensive). |
| T-48-03-02 | Spoofing | shop_id mismatch | mitigate | Probe compares `account_id` from response body to `settings.shop_id`; mismatch logs a WARNING with `reason="shop_id_mismatch"`. Phase 53 operator runbook (deferred) covers operator response. |
| T-48-03-03 | Denial of Service | TLS verification disabled | mitigate | `httpx.AsyncClient` default is `verify=True` (cert verification ON). Plan acceptance criterion forbids `verify=False`. Per Phase 48 security boundary: any future MR that adds `verify=False` must explicitly justify (none in v1.7 scope). |
| T-48-03-04 | Denial of Service | probe hangs blocking startup | mitigate | Per-call timeout `timeout=5.0` on the probe `http.get("me", ...)` overrides the AsyncClient's default. Single-attempt only (D-48-15) — no retry loop that could compound delay. |
| T-48-03-05 | Tampering | base URL switching by env | mitigate | `_YOOKASSA_BASE_URL` is a module-level constant — not configurable. Sandbox flag does NOT switch URL (D-48-08). Defensive against a footgun where an attacker controlling `YOOKASSA_BASE_URL` env could redirect production to an attacker-controlled host. |
| T-48-03-06 | Denial of Service | probe failure aborts app startup | mitigate | D-48-14 / SC2: probe failure is NON-FATAL; factory returns the constructed client regardless. Test coverage in this plan locks the invariant (4 failure-mode tests assert client is still returned). |
