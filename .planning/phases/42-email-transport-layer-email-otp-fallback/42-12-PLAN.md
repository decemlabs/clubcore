<objective>
Fix CR-01: `dispatch_email.py` calls `audit.emit(..., payload=EmailSentPayload(...))` which collapses to `{'payload': <Model>}` and crashes downstream Pydantic validation (`extra='forbid'` + 4 missing required fields). Every `dispatch_email` ARQ job crashes → no `email_sent` audit row → EmailSendLog INSERT rolls back → SC#1 unobservable.

Purpose: Make SC#1 of Phase 42 observable. The flattened-kwarg pattern is the project convention (`app/api/v1/_internal/email/router.py:181-197` for webhook; `app/modules/memberships/service.py` for memberships). The unit test fake_emit pattern is the structural reason this defect escaped CI; this plan also adds an integration-tier test that runs the REAL `audit.emit` validator.

Output:
- `app/workers/tasks/dispatch_email.py` — both audit.emit call sites flattened
- `tests/unit/integrations/email/test_dispatch_email_task.py` — assertions migrated from `kwargs['payload'].field` to `kwargs['field']`
- `tests/integration/email/test_dispatch_email_audit_integration.py` — new integration test exercising real audit.emit + audit_log query
</objective>
