Follow the export_openapi.py docstring + main() shape verbatim, but read source from `openapi.json` rather than `create_app().openapi()` (D-46-08 — avoids re-running FastAPI; uses the already-byte-stable artifact from Plan 01).

The script MUST:

1. Resolve source + target paths cwd-independently:
   ```python
   HERE = pathlib.Path(__file__).resolve()
   SOURCE = HERE.parents[1] / "openapi.json"                                          # apps/backend/openapi.json
   TARGET = HERE.parents[3] / ".planning" / "handoff" / "v1.6-postman.json"           # repo-root/.planning/handoff/...
   ```

2. Load source spec: `spec = json.loads(SOURCE.read_text(encoding="utf-8"))`.

3. Walk `spec["paths"]`. For each path, for each method (`get`, `post`, `put`, `patch`, `delete`):
   - Read the operation's `tags` list. If `'internal'` is in tags, SKIP this operation entirely (D-46-08).
   - Otherwise, build a Postman item dict per the v2.1 shape.

4. Group items hierarchically by path-segment (mirrors v1.4-postman.json layout: `api` → `v1` → `<module>` → operations). Use a recursive defaultdict-style builder. Module name = the 4th path segment (e.g. `/api/v1/users/...` → module `users`; `/api/v1/auth/...` → module `auth`; `/api/v1/_internal/...` would be `_internal` but is filtered already).

5. For each Postman item, populate:
   - `id`: deterministic UUID derived from path+method (e.g. `str(uuid.uuid5(uuid.NAMESPACE_URL, f"{method}:{path}"))`) — keeps the output byte-stable across runs.
   - `name`: operation summary if present, else method-uppercased + path.
   - `request.name`: same as `name`.
   - `request.description.content`: operation description if present, else empty string.
   - `request.description.type`: `"text/plain"`.
   - `request.url.path`: list of path segments split on `/` (skip empty leading element).
   - `request.url.host`: `["{{baseUrl}}"]`.
   - `request.url.query`: `[]`.
   - `request.url.variable`: list of `{key: <name>, value: ""}` for each `{<name>}` placeholder in the path.
   - `request.header`: `[{"key": "Content-Type", "value": "application/json"}, {"key": "Accept", "value": "application/json"}]` for non-GET methods; just the Accept header for GET.
   - `request.method`: method uppercased.
   - `request.body`: omit if no `requestBody` in operation; else `{"mode": "raw", "raw": "{}", "options": {"raw": {"language": "json"}}}`.

6. Wrap the items into the top-level Postman collection structure:
   ```python
   collection = {
       "info": {
           "name": "Sportzal v1.6 — Email channel + Multi-user admin",
           "schema": "https://schema.getpostman.com/json/collection/v2.1.0/collection.json",
           "_postman_id": str(uuid.uuid5(uuid.NAMESPACE_URL, "sportzal-v1.6-handoff")),
       },
       "item": [...],   # the grouped tree built in step 4
       "variable": [{"key": "baseUrl", "value": "http://localhost:8000"}],
   }
   ```

7. Byte-stable write (mirrors export_openapi.py:60):
   ```python
   payload = json.dumps(collection, indent=2, sort_keys=True, ensure_ascii=False) + "\n"
   TARGET.parent.mkdir(parents=True, exist_ok=True)
   TARGET.write_text(payload, encoding="utf-8")
   print(f"Wrote {TARGET} ({len(payload)} bytes).")
   return 0
   ```

8. `main()` returns int; `if __name__ == "__main__": raise SystemExit(main())`.

9. Skip the env-setdefault block from export_openapi.py — this script does NOT call `create_app()` so no env-var bootstrap is needed (per PATTERNS.md A.5 deltas).
