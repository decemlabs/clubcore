## Typography

Named scale — exactly 4 sizes:

| Role | Size | Weight | Line Height | Class / Usage |
|------|------|--------|-------------|---------------|
| Caps label | 11px | 700 | — | `.t-mini` (uppercase, letter-spacing 0.5px) — section labels ("К ОПЛАТЕ", "ЗАКАЗ"), state-meta labels, lock note under pay button |
| Label | 13px | 400 | 1.4 | `.t-small` — secondary meta, promo hint, promo inline error, method info plate text, promo discount/original price lines |
| Body | 15px | 400 | 1.4 | `.t-body` — order subtitle, description text, paying subtext, pending body, state-desc, promo input text |
| Heading | 28px | 700 | 1.15 | `.state-title` — letter-spacing -0.6px, `text-wrap: balance`. Used for success / error / state screen h1. Also used for paying stage label (replaces former 22px). |

Font weights used: **400** (regular) and **650–700** (semibold/bold). No other weights.

Note: weight 650 is a font-weight value supported by variable fonts (SF Pro, Inter Variable).
For fallback fonts this rounds to 600 (semibold). Do not introduce weight 500 or 800.

Inline override (not part of named 4-size scale):

> **44px amount display** — product-critical, pixel-locked to the payment.html mockup.
> Applied as a single-use inline style on `.t-display` only (the "К ОПЛАТЕ" amount line in
> CheckoutSheet). Spec: `font-size: 44px; font-weight: 700; letter-spacing: -1.4px;
> font-variant-numeric: tabular-nums; line-height: 1;`
> This override is intentional and singular. It must not be reused elsewhere.

Nav / top bar title: 15px weight 650, letter-spacing -0.1px (uses `.t-body` size, semibold weight — no new size introduced).
Order item name: 15px weight 650 (uses `.t-body` size, semibold weight — no new size introduced).

Source: `styles.css` type scale + `payment.html` CSS.

## Color

| Role | Token | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--bg)` | Page background, sheet background, state screen background |
| Secondary (30%) | `var(--surface)` / `var(--surface-2)` | Cards, order summary card, info plate, order thumbnail |
| Accent (10%) | `var(--accent)` `#2dd4a4` | Reserved elements listed below |
| Destructive | `var(--danger)` `#dc2626` | Error state icon background fill, inline promo error text, error-kind state icon |

**Accent reserved for exactly:**
1. Primary pay CTA button background (`.btn-accent` = jade fill, dark text `#06120c`)
2. Promo "applied" discount amount text (`var(--accent-deep)`)
3. Focus ring on promo input (`box-shadow: 0 0 0 3px var(--accent-soft)`)
4. Success state icon background (`.state-icon.ok` = `var(--accent)`)
5. Big-spin (processing spinner) top border `var(--accent)`
6. `"Открыть чек"` secondary link color if shown (`var(--accent-deep)`)

**Accent is NOT used for:** body text, card borders, navigation, ghost buttons, general icon strokes.

**State icon tones** (from mockup, map exactly to `errorKind`):
- `ok` (success): `background: var(--accent)`, icon color `#06120c`
- `error` (payment, email-required): `background: var(--danger-soft)`, icon color `var(--danger)`
- `warn` (timeout/offline-unreachable): `background: var(--warn-soft)`, icon color `#a36a16` (light) / `var(--warn)` (dark)
- `info` (pending, canceled, offline): `background: var(--surface-2)`, icon color `var(--text-2)`

**Method info plate** (replaces card picker per D-01):
- Background: `var(--surface)`, border `0.5px solid var(--border)`, border-radius `var(--r-lg)` = 20px
- Lock icon: `var(--text-2)` stroke, 16×16px
- Text: `var(--text-2)`, 13px weight 400

Source: payment.html `:root` tokens (identical to `styles.css`) + CONTEXT.md D-01.

## Accessibility

- All icon-only buttons have `aria-label` in Russian (e.g. `aria-label="Назад"`, `aria-label="Закрыть"`)
- Promo error text rendered as `role="alert"` so screen readers announce it immediately
- State screens announced via `aria-live="polite"` on mount
- Focus management: when error state mounts, focus moves to the primary CTA button
- When success state mounts, focus moves to the "Хорошо" button
- `:focus-visible` ring: `2px solid var(--accent)` (global rule already in `styles.css`)
- Reduced-motion: global `prefers-reduced-motion` rule in `styles.css` covers all animations
