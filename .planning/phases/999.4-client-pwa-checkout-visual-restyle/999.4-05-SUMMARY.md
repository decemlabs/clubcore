## What Was Built

### Task 1: usePromoValidate + promoCode on mutations

**`clientQueries.ts`** changes:
- Added `promoValidate: (code) => [...clientPortalKeys.all, 'promo-validate', code] as const` to `clientPortalKeys`
- Added `PromoValidateResult` interface: `{ discountKopecks: number; newAmountKopecks: number; discountType: 'percentage' | 'fixed' }`
- Added `export function usePromoValidate()` — `useMutation` POSTing to `/api/v1/client/promo/validate` with `{ body: { code, kind, planId } }`. Returns `(res as { data: PromoValidateResult }).data`. No cache invalidation (stateless read).
- Extended `useClientCheckoutMembership` mutationFn arg from `{ planId }` to `{ planId, promoCode?: string }`. Body: `promoCode ? { promoCode } : {}` (D-05).
- Extended `useClientCheckoutPtPackage` mutationFn arg to include `promoCode?: string`. Body: `promoCode ? { promoCode } : {}` (D-05). Idempotency-Key header preserved.

**`data/index.js`** barrel: added `usePromoValidate` to the re-export block.

## Deviations from Plan

### Intentional Scope Additions

**1. [Rule 2 - Missing] Added formatMoney utility to src/utils/format.js**
- **Found during:** Task 2 implementation
- **Issue:** The UI-SPEC mandates `formatMoney(kopecks)` for all amounts, but client-pwa has no `src/shared/lib/money.ts` (that path is admin-web only). The existing `src/utils/format.js` had no money utility; CheckoutSheet was using `.toLocaleString('ru-RU')` directly without kopeck division.
- **Fix:** Added `formatMoney(kopecks)` to `src/utils/format.js` using `Intl.NumberFormat('ru-RU', { style: 'currency', currency: 'RUB' })` with kopeck→ruble division. This is a utility file — no new file needed.
- **Files modified:** `apps/client-pwa/src/utils/format.js`
- **Commit:** 946a5336

**2. [Rule 2 - Missing] Added 4 icons to Icon.jsx (mail, wifiOff, alertCircle, x)**
- **Found during:** Task 2 — CheckoutError requires `mail`, `wifi-off`, `alert-circle` icons per UI-SPEC error table; `x` needed for close button
- **Issue:** Icon.jsx only had `wifi` (not `wifiOff`), `alert` (not `alertCircle`), and `close` (same path as `x`) but not keyed under these camelCase names
- **Fix:** Added all 4 as inline SVG paths matching Lucide stroke style; `x` is identical path to `close` under a new key for semantic clarity
- **Files modified:** `apps/client-pwa/src/components/Icon.jsx`
- **Commit:** 946a5336

No other deviations.
