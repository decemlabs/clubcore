<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| reception session → owner-only reports/audit endpoints | reception must reach neither the data nor the CSV |
| arbitrary JSONB audit `payload` → AuditDetailModal render | server-controlled but arbitrary content rendered to DOM |
| CSV download URL | filter/date params travel in the query string |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-104-06 | Elevation of Privilege | ReportsPage / AuditPage reception | mitigate | Lock-EmptyState early-return BEFORE any hook call; hooks also `enabled:can(...)` (Wave 1). Nav entries `ownerOnly:true`. Reception fires zero owner-only or CSV calls. Backend authoritative. |
| T-104-07 | Tampering / XSS | AuditDetailModal payload render | mitigate | Payload rendered exclusively via `JSON.stringify` into escaped text/<pre>; NO dangerouslySetInnerHTML. Grep-asserted in verify. |
| T-104-08 | Information Disclosure | downloadCsv URLs (reports/audit) | mitigate | GET, cookie auth (`credentials:'include'`), no token/secret in URL; only filter/date params. CSRF-exempt for GET. Owner-only endpoints — reception cannot trigger (gated). |
| T-104-SC | Tampering | npm/pnpm installs | accept | No new dependencies; no install task. |
</threat_model>
