# Quick Task 260606-u22: Replace BookScreen with the new «Запись» design (hybrid)

## Description

Put the new «Запись» booking design (ported in 260606-toj as `BookingScreen.jsx`) **in
place of** the wired `BookScreen.jsx`. Integration follows the szy precedent: no device
frame, shared design tokens + the app's existing global classes, wired to the real API.

**User decisions (this session):**
- Prices/payment (trainer prices, duration 30/60/90, "К оплате … с карты") — **decor**
  (no backend for them; booking is PT-package-funded, no charge at booking).
- Trainer richness + slot states (rating ★, exp, «Топ»/«цена» filters, busy slots,
  "всё занято"/"ближайшее окно") — **decor** (no API data).
- The screen must **really create a booking** (hybrid): real trainers/slots from
  `/client/slots` and a real `POST /client/booking`; decor rendered on top.
