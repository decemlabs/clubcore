# Summary — 260606-u22: Replace BookScreen with the new «Запись» design (hybrid)

**One-liner:** Rewrote the wired `BookScreen.jsx` with the new «Запись» design (from the
260606-toj mockup) — no device frame, shared tokens + the app's global design classes —
wired to the real `/client/slots` + `/client/booking` API, with trainer ratings/exp/price,
duration 30/60/90 + prices, and «Топ»/«цена» filters kept as **deterministic decor** over
the real `trainerId`. Gates green, browser-verified end-to-end.

## What was done

- **`BookScreen.jsx` rewritten** keeping the export name `BookScreen` and the exact props
  contract `{ onTab, onOpenManage, onOpenTrainer, onCheckout, onConfirmFlow, onOpenPlans }`
  — `App.jsx` (BookRoute) untouched.
- **Real data / real booking (hybrid):**
  - `useClientAvailableSlots()` → calendar days, trainers-for-day, and per-trainer slots,
    all bucketed in **Europe/Moscow** (Intl, reused MSK helpers).
  - `useCreateBooking({ slotId, idempotencyKey })` on «Подтвердить»; `no_active_pt_package`
    422 → `onOpenPlans()` (CBOOK-04), `slot_already_booked` → inline error, success → done.
  - Loading / error (LoadError + retry) / empty («Нет слотов» → Купить абонемент) states kept.
- **Decor (deterministic hash on `trainerId`, stable across renders):** rating ★, exp, price,
  specialization, avatar colour; duration toggle 30/60/90 + live price (booking ignores
  duration — fixed real slot); «Все / ★ Топ / До 2200 ₽» filters operate on decor values;
  review «К оплате … спишется с карты» shown as decor. Per the user's "оставить как декор"
  decision — the real booking is PT-package-funded (no card charge), and a missing package
  routes to Plans, so the decor "card charge" text never drives a wrong real charge.
  Busy/fully-booked/nearest-window kept as code paths (only free slots are returned, so a
  trainer with 0 slots on the selected day shows "всё занято" + jump to nearest real day).
- **Shell integration:** removed the mockup's device frame / island / fake status bar /
  own tab bar — renders inside `.page` + `<StatusBar/>` + `.scroller`; the app shell draws
  the tab bar (hidden on confirm/done via `onConfirmFlow`). Reused global design classes
  (`.card`/`.press`/`.cal-day`/`.period-card`/`.slot-chip`/`.chip`/`.ava`/`.btn`/`.fade-up`/
  `.scale-in`/`.toast`/`.t-*`) — already the same design system; inlined only the
  mockup-specific bits (book-summary CTA, trainer-card decor). Period sunrise/sun/moon icons
  inlined as SVG (not in the app `Icon` set). `Icon`/`RowItem`/`Divider`/`SearchBar` reused.
- **«Подробнее»** → `onOpenTrainer({ id, name, initials, bg, color })` reuses the existing
  wired `TrainerDetailSheet` (real photo/spec/bio). Done «Управлять записью» →
  `onOpenManage(createdBooking)`; «Готово» → `onTab('home')`. No `window.location.href`.
- Removed the superseded standalone `BookingScreen.jsx` (260606-toj) — git history keeps it.
- Added `BookScreen.test.jsx` (5 smoke tests) — the old BookScreen had no test.
