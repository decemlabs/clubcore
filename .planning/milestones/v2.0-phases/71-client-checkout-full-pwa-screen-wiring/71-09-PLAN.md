<objective>
Close the BLOCKER from 71-HUMAN-UAT test 1: every price/duration renders "не число"
(NaN) and "undefined дней" because the frontend adapters read snake_case
(`price_kopecks`, `duration_days`, `days_until_end`, `plan_name_snapshot`,
`start_date`, `end_date`, …) while the backend serializes **camelCase**
(`priceKopecks`, `durationDays`, …) via Pydantic `alias_generator=to_camel`.

Canonical-contract decision (made here, documented for the executor): the API wire
format is **camelCase** — confirmed authoritative in
`packages/api-client/src/schema.d.ts` (every Client* response schema:
`ClientCatalogPlanResponse.priceKopecks/durationDays`,
`ClientCatalogPtPackageResponse.sessionCount/priceKopecks`,
`ClientMembershipResponse.planNameSnapshot/startDate/endDate/daysUntilEnd/expiringSoon`,
`ClientHomeResponse.nextBooking`, `ClientNextBookingResponse.startTime/trainerName`,
`ClientVisitItem.gymDate/checkedInAt`, payment `subjectKind/amountKopecks/receivedAt`,
pt-session `performedAt/trainerNameSnapshot/cancelledAt`).

**Fix the adapters to camelCase** (do NOT add a snake_case conversion at the
clientFetcher boundary). Rationale: the typed `paths`/`components` schema and the
staff transport are uniformly camelCase; converting at the boundary would fight the
canonical typed contract and silently diverge the PWA from the generated types. The
adapters are the wrong layer; align them to the contract.

Blast radius is wider than the UAT's two flagged spots: a grep of the wired screens
shows snake_case reads in PlansSheet (membership + PT), HomeScreen (membership +
nextBooking + UpcomingCard + HomeMinimal booking), and ProfileScreen (membership +
visits + pt-sessions + payments). The UAT only *saw* the plan-price NaN because the
catalog was the first populated surface; the rest are latent and must all be fixed.

This plan also seeds the catalog (Gap 4) so the price fix is verifiable end-to-end
without a manual SQL insert.

Purpose: Make all wired screens render real numbers/dates/names from the camelCase API.
Output: camelCase adapters across the three wired screens + a dev catalog seed.
</objective>
