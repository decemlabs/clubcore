> post-payment receipt-email.
>

### Screen 1: OnboardingScreen (`/onboarding` route)

New file: `apps/client-pwa/src/screens/OnboardingScreen.jsx`

**Layout skeleton:**
```
<div class="screen">
  <TopBar />        {/* back | progress (3 segs) | skip */}
  <Slides />        {/* 4 slides in a position:absolute container */}
  <DoneOverlay />   {/* position:absolute; opacity 0→1 on finish */}

```

**TopBar:**
- Back button: `36×36px` pill, `hidden` attribute on step 0, visible on steps 1–3
- Progress: 3 segments (not 4 — each segment = one reviewable step; step 3 = review/confirmation; segments fill left-to-right as user advances). Segment style: `flex: 1; height: 5px; border-radius: 999px; background: var(--border-strong)`. Filled inner `i`: `background: var(--accent); transition: width 0.4s cubic-bezier(0.32, 0.72, 0.2, 1)`
- Skip button: text "Пропустить" (steps 0–2), "Заполню позже" (step 3). `color: var(--text-3); font-size: 14px; font-weight: 600`. Calls skip handler → fires `onboarding_completed_at` flag write (D-05) → navigate to newbie Home.

**Slide transition:**
- Container: `position: relative; overflow: hidden` (fills remaining screen height)
- Each slide: `position: absolute; inset: 0; opacity: 0; transform: translateX(36px)` — inactive
- Active slide: `opacity: 1; transform: translateX(0)` — `transition: transform 0.34s cubic-bezier(0.32, 0.72, 0.2, 1), opacity 0.24s ease`
- Past slide: `opacity: 0; transform: translateX(-36px)`
- React state: `const [idx, setIdx] = React.useState(0)` — drives slide class

**Step 0 — Имя:**
- Spot illustration: halo (radial-gradient `var(--accent)` 20%), two dashed rings (accent 42%/24% opacity), 3 floating decoration chips, central member-card scene
- Title: "Как тебя зовут?"
- Subtitle: "Так мы будем обращаться к тебе в зале и в приложении."

- CTA is always enabled (name is optional — user can skip with empty string per D-08)

**Step 1 — Цель:**

- Title: "Какая цель?"
- Subtitle: "Подберём программу и подсказки под неё. Можно поменять потом."

**Step 2 — Рост и вес:**

## Accessibility

- All icon-only buttons have `aria-label` in Russian (e.g. `aria-label="Назад"`, `aria-label="Пропустить"`, `aria-label="Очистить"`)
- Onboarding slide container: active slide has `aria-hidden="false"`, inactive slides have `aria-hidden="true"` to prevent screen reader traversal of off-screen steps
- Goal cards: use `<button>` elements (not `<div>`) for native keyboard/screen reader support; selected state expressed via `aria-pressed="true/false"`
- Email validation error: `role="alert"` on `.field-hint.err` to announce immediately on blur
- Range sliders: `<input type="range">` is natively accessible; add `aria-label="Рост"` / `aria-label="Вес"` if `<label>` is not adjacent
- Topbar skip button: descriptive text (not an icon) — no aria-label needed
- `:focus-visible` ring: `2px solid var(--accent); outline-offset: 2px` — global rule in `styles.css` already handles this
- Reduced-motion: `@media (prefers-reduced-motion: reduce)` global rule in `styles.css` collapses all transition durations to 0.001ms
