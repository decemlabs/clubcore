Pydantic `AUDIT_PAYLOAD_SCHEMAS[(pt_session_recorded, pt_session)].model_validate(payload)` accepts both str and UUID (its `performed_by_user_id: UUID` field coerces strings) but does NOT mutate the original dict — so the raw UUID survives validation and trips the JSON encoder downstream. Fix: `performed_by_user_id=str(actor.id)`. This bug shipped in commit 8d8ed09 (Phase 34-02) and went undetected because the affected integration test (`test_concurrent_record_pt_session_decrement_at_db_layer`) was authored under the same commit but never successfully run end-to-end."
