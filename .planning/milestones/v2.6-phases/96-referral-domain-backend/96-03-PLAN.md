<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → POST /referral/capture | Untrusted body crosses here. Body carries only `{code}`; referee identity is the require_client() principal, never the body (IDOR). |
| unauthenticated internet → GET /i/<code> | Public, unauthenticated. Untrusted code path param; response must leak no PII. |
| reception staff → /referral/config | Reception must be denied (403); only owner may read/write reward amounts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-96-05 | Spoofing / Elevation | capture referee identity | mitigate | `capture_referral` receives the referee id from `require_client()` principal as an explicit argument; ReferralCaptureRequest has no id field (extra='forbid'). Test asserts the principal id wins regardless of body. |
| T-96-06 | Information Disclosure | GET /i/<code> response | mitigate | resolve_public_code returns ONLY {valid, referrerFirstName, welcomeBonusKopecks}; first name only, no client_id, no last name. Unknown code → valid:false 200 (no existence-difference oracle). Test asserts exact key set. |
| T-96-07 | Elevation of Privilege | /referral/config owner gate | mitigate | `require_permission(Action.EDIT, Resource.GYM)` on GET+PUT; PUT declares require_permission BEFORE verify_csrf (RBAC-04). Reuses existing Resource.GYM — no admin-web edit, CISO-01 parity intact. Reception 403 asserted. |
| T-96-08 | Tampering / DoS | self-referral abuse | mitigate | Self-referral (resolved referrer == principal) → 422. Asserted in test. |
| T-96-09 | Tampering | double-capture race | mitigate | App-level idempotency (get_capture_by_referee) + DB UNIQUE on referee_client_id (96-02). A racing second insert violates the constraint rather than creating a duplicate binding. |
| T-96-10 | Repudiation | mint/capture audit | mitigate | referral_code_generated + referral_captured emitted co-transactionally, gated on real inserts only (no duplicate audit on idempotent paths). |
| T-96-SC | Tampering | python deps | accept | No new package installs in this plan (secrets is stdlib). RESEARCH Package Legitimacy Gate N/A. |
</threat_model>
