| T-109-01 | Information Disclosure | profile_updated audit payload | mitigate | Task 1: audit payload carries only `changed_fields` markers — NO password, hash, or raw-email value (no leakage in audit log) |

| T-109-06 | Information Disclosure | MeResponse echo / 204 | accept | PATCH echoes the existing MeResponse (no password/hash field); change-password returns 204 with empty body — no sensitive data in either response |
