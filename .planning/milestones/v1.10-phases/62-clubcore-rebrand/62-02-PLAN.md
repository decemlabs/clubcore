<objective>
G-2 atomic-commit group: migrate all three frontend localStorage namespaces from `sportzal:*:v1` to `clubcore:*:v2` with a one-shot pre-rehydrate copy-on-read+delete-old migrator. Implements D-62-06 back-compat strategy.

The migrator runs once per browser on first v1.10 boot, copies legacy keys to the new namespace, deletes the legacy keys, and Zustand `persist` then rehydrates from the new keys cleanly. Removal of the shim is scheduled for v1.11 Phase 67 RUN-07.

Output: 4 edited files + 1 new migrator block in main.tsx. All five Zustand `version` bumps + key swaps + bootstrap fallback land in ONE commit per D-62-11 (mismatched keys cause FOUC or rehydrate failure).
</objective>
