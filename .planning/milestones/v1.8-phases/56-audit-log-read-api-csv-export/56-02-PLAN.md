CSV CORRECTNESS PINS (D-11..D-14 — do not let the executor reinvent):
- BOM is the Python escape "\ufeff" (U+FEFF). A literal U+FEFF glyph in source is a defect — write the \ufeff escape.
- Delimiter comma, line terminator \r\n, QUOTE_MINIMAL — all provided by the stdlib csv "excel" dialect. Use csv.writer with dialect="excel" over a per-row io.StringIO; do not hand-roll escaping.
- BOM is yielded as the FIRST chunk, before the header row.
- Money: signed kopecks → rubles via f"{kopecks/100:.2f}" — 2 decimals, PERIOD decimal, no thousands grouping (e.g. 250000 → "2500.00", -100 → "-1.00") (D-13). Honors the locked RFC-4180 SC#4; do NOT switch to comma-decimal/semicolon dialect (that is a deferred idea, not this phase).
- Dates: report period buckets keep YYYY-MM-DD (day) / YYYY-MM (month) as-is; audit createdAt → "YYYY-MM-DD HH:MM:SS" in Europe/Moscow, no offset suffix (D-14).
- audit-log.csv streams ALL filtered rows (no pagination, D-16) via stream_scalars; payload serialized as a compact JSON string in one cell.
- audit-log.csv `from`/`to` filters arrive via route-level Query(alias="from"/"to") (mirroring Plan 01) and are threaded into the stream/validation as keyword args — NOT read off the AuditLogQuery model.
- Response: media_type="text/csv; charset=utf-8"; Content-Disposition: attachment; filename="<name>.csv".
- CSV routes return StreamingResponse directly — NO ResponseEnvelope, NO response_model=, NO envelope() call.
- Same RBAC as JSON siblings: report .csv → require_permission(Action.VIEW, Resource.REPORTS); audit-log.csv → require_permission(Action.LIST, Resource.AUDIT_LOG). Reception → 403.
