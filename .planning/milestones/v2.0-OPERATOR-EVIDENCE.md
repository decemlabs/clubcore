## RUN-01 — ЮKassa Checkout (OPERATOR-PENDING)

**Status:** OPERATOR-PENDING
**Procedure:** `.planning/handoff/clubcore-v2.0-runbook.md` § 5

### Trigger condition

Execute RUN-01 when ALL of the following are true:
1. ЮKassa sandbox credentials are provisioned: a `YOOKASSA_SHOP_ID` + a
   `test_`-prefixed `YOOKASSA_SECRET_KEY` + `YOOKASSA_RETURN_URL`.
2. `YOOKASSA_SANDBOX=true` is confirmed set in `apps/backend/.env`.
3. Backend is reloaded: `docker compose up -d --force-recreate backend`.

### What to execute (when trigger fires)

1. `POST /api/v1/client/checkout/memberships/<plan_id>` → receive `paymentId` +
   `confirmationUrl`.
2. Open `confirmationUrl` in browser → enter test card `5555 5555 5555 4477`.
3. After redirect, fire manual webhook:
   `POST /api/v1/_internal/yookassa/webhook` with the **REAL** `paymentId` from
   step 1 (never fabricate — D-67-03 / T-72-11).
4. `GET /api/v1/client/payments/<paymentId>/status` → `status: succeeded,
   membershipActivated: true`.
5. `GET /api/v1/client/membership` → `status: active`.
