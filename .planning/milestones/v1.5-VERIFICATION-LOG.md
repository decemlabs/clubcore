## Recipe (manual verification sweep)

For future re-runs of the Phase 40-shaped v1.5 verification sweep:

1. **Pre-flight gate:** confirm `SECRET_KEY` ≥48 bytes; `docker compose` available;
   `uv` available; `pnpm` available; `.env.compose.verification` exists and is gitignored
   (Telegram sandbox bot token + test client telegram user id).
2. **Live stack up:**
   ```bash
   docker compose -f apps/backend/docker-compose.yml down -v
   docker compose --env-file .env.compose.verification -f apps/backend/docker-compose.yml up -d
   ```
   Wait until `docker compose ps` shows backend + postgres + redis + telegram-bot + arq-worker all `Up`.
   Capture `verified_started:` timestamp via `date -u +%Y-%m-%dT%H:%M:%SZ`.
3. **Seed baseline fixtures:**
   ```bash
   cd apps/backend && uv run python -m scripts.seed_v1_4_verification_fixtures
   ```
   (Idempotent seed reused from v1.4; v1.5 booking-specific fixtures are appended inline by run.sh.)
4. **6 curl operator scenarios (VER-05):**
   ```bash
   bash .planning/milestones/v1.5-verification-evidence/run.sh
   ```
   Writes 6 transcripts under `verification-evidence/curl/0N_*.http`; exits 0 only on full PASS.
5. **2 Telegram sandbox scenarios (VER-06):**
   - From the linked test Telegram account, send `/book` to the sandbox bot.
   - Capture 2 screenshots: keyboard render (`telegram/01_happy_path_keyboard.png`) + after-tap confirmation (`telegram/02_happy_path_confirmed.png`).
   - From a second account (or after `UPDATE pt_packages SET sessions_remaining=0` on the first client), send `/book` → capture the anti-oracle DM (`telegram/03_anti_oracle_denied.png`).
   - Byte-exact-compare the anti-oracle DM against `apps/backend/app/modules/bookings/notifications.py:35`.
   - **PII:** Redact 9–10-digit chat IDs in all 3 screenshots before commit.
6. **2 cron one-shot scenarios (VER-07):**
   ```bash
   cd apps/backend && uv run python -m scripts.run_no_show_cron_once   # VER-07a
   cd apps/backend && uv run python -m scripts.run_booking_reminders_once   # VER-07b first run
   cd apps/backend && uv run python -m scripts.run_booking_reminders_once   # VER-07b second run (idempotency proof, delta_dms=0)
   ```
   Capture stdout + DB diffs to `crons/run_no_show.log` + `crons/run_reminders.log`.
7. **5 CI gates (VER-08):**
   ```bash
   cd apps/backend && uv run ruff check . 2>&1 | tee /tmp/ci_ruff.txt
   cd apps/backend && uv run mypy --strict app 2>&1 | tee /tmp/ci_mypy.txt
   cd apps/backend && uv run pytest -q 2>&1 | tail -30 | tee /tmp/ci_pytest.txt
   git diff --exit-code apps/backend/openapi.json; echo "exit_code: $?"
   git diff --exit-code packages/api-client/src/schema.d.ts; echo "exit_code: $?"
   ```
   Then push the branch + capture GHA run URL pinned to HEAD into `ci-gates.md` per D-40-17.
8. **Finalize:** populate this VERIFICATION-LOG (`human_verification:` `actual:` fields,
