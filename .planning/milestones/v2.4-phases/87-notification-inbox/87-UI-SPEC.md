## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Unread dot right-offset adjustment (bell button: top 8px, right 9px — see Bell Button section) |
| sm | 8px | Row internal gap (icon container + content block); section top padding above list |
| xs+ | 12px | Notification row vertical padding (inherited row pattern) |
| md | 16px | Sheet horizontal padding; card internal padding; row horizontal padding |
| lg | 24px | Empty state vertical padding top/bottom; load-more bottom padding |
| xl | 32px | Bottom safe-area padding |
| 2xl | 48px | Empty state vertical centering offset |
| 3xl | 64px | Not used in this sheet |

Exceptions (inherited from existing shipped components — do not change):

- `xs+` (12px) is a multiple of 4 but sits outside the canonical 8-point set {4,8,16,24,32,48,64}. It is **inherited from the existing shipped row pattern** (BonusHistorySheet / LoyaltySheet compact rows — `padding: '12px 16px'`) and is replicated here for visual consistency — not a new value introduced by this phase. Documented exception per Phase 86 UI-SPEC precedent.
- `SubSheetHeader` is reused as-is. Its internal padding is owned by the shared component and is not governed by this phase's spacing contract.
- Sheet entry animation uses `position: absolute; inset: 0; z-index: 220` — no spacing exception; matches the existing sub-sheet pattern.
- Bell button unread dot: `top: 8, right: 9` — inherited from the existing `bellBtn` component in `HomeScreen.jsx` (line 143-148). Not a new value; not modified by this phase.
- Hairline dividers use `height: 0.5px` — sub-pixel value for retina hairline; inherited from BonusRow / LoyaltySheet divider pattern.

No undocumented non-multiple-of-4 values remain.

## Layout: NotificationsSheet Structure

The sheet is a **full-screen sub-sheet** (z-index 220, `sheet-up` animation, `position: absolute; inset: 0`). It is a read-mostly sheet with a single "mark all" mutation action.

Shell is copied from `BonusHistorySheet` (LoyaltySheet.jsx) — same `StatusBar` / `SubSheetHeader` / `PullToRefresh` / scroller frame.

### Visual Sections (top to bottom)

```
StatusBar
SubSheetHeader ("Уведомления") + "Отметить все" action (trailing, if unreadCount > 0)
─── PullToRefresh / .scroller ──────────────────────
  [section label: "УВЕДОМЛЕНИЯ"]
  [notification list — card, paginated, newest-first]
    Each row: icon container + title + body + timestamp + unread dot (if unread)
  [load more button — if hasMore]
  [empty state — if no items after load]
  [bottom padding: 32px]
────────────────────────────────────────────────────
```

### SubSheetHeader + Mark-All Action

`SubSheetHeader` is used as-is (opaque — do not enumerate its internals).

The "mark all" action is appended as a trailing element in the header row — rendered only when `unreadCount > 0`.

```
<button className="press" onClick={handleMarkAll} style={{
  background: 'none', border: 'none', padding: '0 16px 0 0',
  color: 'var(--accent-deep)', cursor: 'pointer',
}}>
  <span className="t-small" style={{ color: 'var(--accent-deep)', fontWeight: 600 }}>
    Всё прочитано
  </span>
</button>
```

Optimistic update: on tap, immediately set all rendered items to `readAt = new Date().toISOString()` in local state; rollback on API error via `onError` in the mutation.

### Notification Row

Container: inside `.card` with `padding: 0; overflow: hidden`.

Each row: `padding: 12px 16px; display: flex; align-items: flex-start; gap: 12`

Structure:
```
[icon container 32×32]  [content flex:1]  [unread dot — only if readAt === null]
```

**Icon container** (32×32, border-radius 8px):
- `display: flex; align-items: center; justify-content: center; flex-shrink: 0`
- Background/color per kind (see Color section).

**Icon per notification kind** (size 16, `color="currentColor"`):
| Kind | Icon name |
|------|-----------|
| `booking_confirmed` | `calendar` |
| `booking_cancelled_by_client` | `close` |
| `booking_cancelled_by_owner` | `close` |
| `booking_rescheduled` | `history` |
| `payment_succeeded` | `card` |
| `autopay_charge_succeeded` | `card` |
| `autopay_charge_failed` | `alertCircle` |

All icons already exist in `Icon.jsx`.

**Content block** (`flex: 1; min-width: 0`):
- Title: `.t-body` `fontWeight: 700; color: var(--text)` — the denormalized `title` string from API.
- Body: `.t-small` `marginTop: 1; color: var(--text-2)` — the denormalized `body` string.
- Timestamp: `.t-small` `marginTop: 2; color: var(--text-3)` — relative time string derived client-side (see Timestamp Derivation).

**Unread dot** (trailing, vertically centered):
- `width: 8px; height: 8px; border-radius: 999px; background: var(--accent); flex-shrink: 0; align-self: center`
- Rendered only when `readAt === null`.

**Hairline divider** between rows:
- `height: 0.5px; background: var(--border); marginLeft: 60`
- 60px = row horizontal padding (16px) + icon container (32px) + gap (12px) = 60px, multiple of 4.

### Mark-single on open (read on view)

When a row becomes visible for the first time (sheet opens and row is in the initial page), call `PATCH /client/notifications/{id}/read` silently. No visible state change on the row itself beyond the dot disappearing. Optimistic: set `readAt` immediately in local state before API call.

### Timestamp Derivation

Client-side relative time from `createdAt` ISO string (no date-fns — follows `D-82-01` Intl-only precedent):

```js
function formatRelativeTime(isoString) {
  const now = Date.now()
  const then = new Date(isoString).getTime()
  const diffMs = now - then
  const diffMin = Math.floor(diffMs / 60000)
  if (diffMin < 2)   return 'только что'
  if (diffMin < 60)  return `${diffMin} мин. назад`
  const diffH = Math.floor(diffMin / 60)
  if (diffH < 24)    return `${diffH} ч. назад`
  const diffD = Math.floor(diffH / 24)
  if (diffD === 1)   return 'вчера'
  if (diffD < 7)     return `${diffD} дн. назад`
  // Fallback: absolute date in ru-RU
  return new Intl.DateTimeFormat('ru-RU', {
    day: 'numeric', month: 'short', timeZone: 'Europe/Moscow',
  }).format(new Date(isoString))
}
```

## Bell Entry Point (HomeScreen)

The bell button exists in both HomeScreen variants (`ActiveSubHome` and `NewbieHome`). This phase adds the unread badge to the existing bell button — it does not change the button's shape, size, or position.

### Existing bell button structure (HomeScreen.jsx lines 135-148, 859-874)

The button is already rendered as a 38×38 surface with `border-radius: 12px`. This phase:

1. Passes `unreadCount` (from the `useClientNotifications(page=1)` query response meta) down as a prop to the screen.
2. Renders the existing unread dot `(unread > 0)` condition that is already coded in the ActiveSub variant's `bellBtn` (line 142-148) — extend the same dot to the `NewbieHome` variant's bell button (line 859-874), which currently has no dot.

Unread dot spec (both variants, consistent):
- `position: absolute; top: 8px; right: 9px; width: 7px; height: 7px`
- `border-radius: 999px; background: '#f43f5e'; border: '2px solid var(--surface)'`
- Source: existing ActiveSub bellBtn code — do not change the values, only ensure consistency with the Newbie variant.

No TabBar badge is introduced for notifications in this phase. TabBar currently has 4 tabs (home / book / chat / profile); notifications are accessed via the bell on the Home screen header, not via a tab. The existing `unreadChat` badge pattern on the TabBar is the reference for if/when a tab badge is ever needed — this phase does not add one.

## Interaction Contract

| Interaction | Behavior |
|-------------|----------|
| Bell button tap (HomeScreen) | `ui.setNotifsOpen(true)` — opens NotificationsSheet via existing `SheetGate` wiring |
| Sheet open | Fetch page 1; optimistically mark first-page unread items as read after 800ms (debounced, fire-and-forget); `unreadCount` update reflected on next query refresh |
| Mark-all tap ("Всё прочитано") | `PATCH /client/notifications/read-all`; optimistic: set all rendered `readAt` in local state immediately; on error rollback + Sonner toast "Не удалось отметить прочитанными" |
| Individual row mark-read | Fires on first render of the row (sheet open); `PATCH /client/notifications/{id}/read`; optimistic dot removal |
| Load more tap | Increment page counter; accumulate items (dedup by id, same pattern as BonusHistorySheet) |
| Pull-to-refresh | Reset to page 1, clear accumulated items, refetch |
| Close (chevronLeft) | `onClose()` prop — matches SubSheetHeader pattern |
| Error state pull-to-refresh | Re-triggers the query; skeleton replaces error during re-fetch |
