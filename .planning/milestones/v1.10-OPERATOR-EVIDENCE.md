## RUN-08-local-db-smoke (pg_dump/restore round-trip)

> Restore target = dedicated database name `clubcore_smoke` (NOT live `clubcore` DB). This isolation ensures the live `clubcore` DB is byte-untouched during the smoke; Alembic migration state on the live DB is preserved.

### Commands executed

```bash
# Executed: 2026-05-26T14:09:37Z
# pg client binary: /usr/local/Cellar/libpq/18.4/bin (PostgreSQL 18.4 client vs PostgreSQL 16.13 server)

# Step 1 — Backup live clubcore DB (READ-ONLY)
PGPASSWORD=app /usr/local/Cellar/libpq/18.4/bin/pg_dump -h localhost -p 5432 -U app -F c -f /tmp/clubcore-smoke.dump clubcore
chmod 600 /tmp/clubcore-smoke.dump

# Step 2 — Create isolated target DB
PGPASSWORD=app /usr/local/Cellar/libpq/18.4/bin/createdb -h localhost -p 5432 -U app clubcore_smoke

# Step 3 — Restore into clubcore_smoke (NOT touching live)
PGPASSWORD=app /usr/local/Cellar/libpq/18.4/bin/pg_restore -h localhost -p 5432 -U app -d clubcore_smoke /tmp/clubcore-smoke.dump

# Step 4 — Row-count parity (live vs smoke)
# Note: table is named `memberships` not `subscriptions` in the actual schema
PGPASSWORD=app /usr/local/Cellar/libpq/18.4/bin/psql -h localhost -p 5432 -U app -d clubcore \
  -c "SELECT 'live' AS db, 'clients' AS tbl, count(*) FROM clients UNION ALL SELECT 'live', 'memberships', count(*) FROM memberships UNION ALL SELECT 'live', 'payments', count(*) FROM payments;"
PGPASSWORD=app /usr/local/Cellar/libpq/18.4/bin/psql -h localhost -p 5432 -U app -d clubcore_smoke \
  -c "SELECT 'smoke' AS db, 'clients' AS tbl, count(*) FROM clients UNION ALL SELECT 'smoke', 'memberships', count(*) FROM memberships UNION ALL SELECT 'smoke', 'payments', count(*) FROM payments;"

# Step 5 — Alembic version on live (confirms byte-untouched)
PGPASSWORD=app /usr/local/Cellar/libpq/18.4/bin/psql -h localhost -p 5432 -U app -d clubcore \
  -c "SELECT version_num FROM alembic_version;"

# Step 6 — Cleanup
PGPASSWORD=app /usr/local/Cellar/libpq/18.4/bin/dropdb -h localhost -p 5432 -U app clubcore_smoke
rm -f /tmp/clubcore-smoke.dump
```
