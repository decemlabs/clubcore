|----------|-------------|
| device file picker → browser | user-selected file enters the app; validated client-side then re-validated server-side (Phase 92 magic bytes) |
| browser → REST upload/send | attachmentId + body cross to the server; ownership derived from cc_client_access only |
| attachment URL → <img> | IDOR-safe serve path (Phase 92); same-origin cookie auth; nosniff + Content-Disposition set server-side |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-94-05 | Tampering | client-side file validation | accept | client check is UX-only; authoritative magic-byte + 5MB validation is server-side (Phase 92); a bypassed client check cannot store a bad file |
| T-94-06 | Elevation/IDOR | photo bubble <img src> | mitigate | renders only attachment.url returned by the server for the client's own thread; cross-client UUID fetch returns 404 server-side (Phase 92) |
