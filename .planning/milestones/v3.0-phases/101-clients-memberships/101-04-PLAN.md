<interface_context>
**Backend wire contract (camelCase aliases — confirmed in 101-PATTERNS §Visits & Payments + backend read):**

Visits (`app/modules/visits/`):
- `GET /api/v1/visits?clientId=…` → `{ data: { items: Visit[], total, page, pageSize } }`. reception+owner (VIEW, VISITS).
- `Visit` wire (camelCase via `to_camel` alias on the snake_case ORM fields): id, clientId, membershipId, checkedInAt, gymDate, channel (string), checkedInBy? (nullable), createdAt.

Payments (`app/modules/payments/`):
- **`GET /api/v1/payments/by-client/{client_id}`** → `{ data: { items: Payment[], total, page, pageSize } }`. reception+owner via scoped Depends. **The path is `/by-client/{client_id}` — NOT `GET /payments?clientId=`. The path param key is `client_id` (snake in the URL pattern).**
- `Payment` wire: id, subjectKind (string), subjectId, amountKopecks (int), method (string), receivedAt, receivedByUserId, refundOf? (nullable), auditLogId? (nullable).

Memberships:
- `useMembershipsByClient(clientId)` already exists in `features/memberships/api.ts` (from 101-03) — reuse it directly; do not re-implement.

**Transport / error facts:** `staffRequest('get', '/api/v1/payments/by-client/{client_id}', { params: { client_id: clientId } })` then `Schema.parse(raw).data`. Re-export `ApiError` from each new api.ts. Use `params` (not `query`) for the payments path interpolation; use `query:{clientId}` for visits.

**UI-SPEC §Surface 1 (per-tab states):** each tab renders its OWN inline `<PageError onRetry/>` on error (do NOT bubble to full-page) and an inline `EmptyState` (no icon tile) when empty — copy: Активность «Нет активности» / «Визиты клиента появятся здесь.»; Тренировки «Нет тренировок» / «Персональные тренировки появятся здесь.»; Платежи «Нет платежей» / «История платежей клиента появятся здесь.». Tab labels: Активность=visits, Тренировки=PT (read-only display of PT data available; if no dedicated PT-by-client read is in scope, render from pt-packages by-client if available else show empty state), Платежи=payments.

**format helpers:** money = `formatRub`; dates/time = `formatDateRu` / `formatTime`.
</interface_context>
