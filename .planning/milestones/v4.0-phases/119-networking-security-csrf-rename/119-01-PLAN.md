| Boundary | Description |
|----------|-------------|
| Internet → Traefik ingress | Untrusted client traffic enters the cluster here; TLS terminates at the router |
| Ingress → backend/frontends | In-cluster east-west traffic to ClusterIP Services |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-119-01 | Information Disclosure | Plain-HTTP ingress traffic | mitigate | HTTPS-redirect Middleware (redirectScheme permanent) + router.tls=true on websecure entrypoint (NET-01) |
| T-119-02 | Spoofing | TLS certificate authenticity | mitigate (local) / transfer (prod) | cert-manager selfSigned for k3d, letsencrypt-staging iterative; LE-prod issuance operator-pending (NET-03) |
| T-119-03 | Denial of Service | WebSocket connection exhaustion | accept | Single-club scale, replicas:1; rate-limit/backpressure tracked in SEC-06 proxy rate-limit retro (plan 03), not ingress scope |
| T-119-04 | Tampering | Cached authed API data in SPA nginx | mitigate | client-pwa nginx already sets /api/* Cache-Control: no-store + sw.js no-cache (NET-04, Phase 118 IMG-03) — verified here |
| T-119-SC | Tampering | npm/pip/cargo installs | mitigate | No new package installs in this plan (pure k8s manifests); slopcheck N/A |
