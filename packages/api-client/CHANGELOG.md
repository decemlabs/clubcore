# Changelog

All notable changes to `@clubcore/api-client` are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased] — 2026-05-29 — Cookie/domain renames (NAME-01, closes D-11-CSRF-DEFER)

### Changed

- NAME-01: Auth cookie names updated from sportzal-era identifiers to clubcore equivalents — `cc_access`, `cc_refresh`, `clubcore_csrf`; `openapi.json` + `schema.d.ts` regenerated byte-stably; contract-freeze-v1.11.0 baseline intentionally shifted (pre-integration, cheapest moment). Closes D-11-CSRF-DEFER.
- Fetcher `readCsrfCookie()` reads `clubcore_csrf` cookie to match renamed server constant; byte-equality note updated to reference the new name.
- Email domain in all backend templates updated: `mail.clubcore.ru` (legacy `mail.sportzal-era` domain replaced).
- Newman `augment-collection.mjs` and active Postman collection updated to extract `clubcore_csrf`.
- Active auth runbook updated to reference new cookie names throughout.

## [Unreleased] — 2026-05-26 — v1.11.0 Contract Freeze

### Added

- FRZ-01: `info.title="clubcore API"` (was `"Sportzal API"`), `info.version="1.11.0"` (was `"1.1.0"`), `info.description` populated with contract-freeze status; `openapi.json` + `packages/api-client/src/schema.d.ts` regenerated byte-stably in the same commit; drift gate green.
- FRZ-02: All 102+ auto-generated operation IDs cleaned via `generate_unique_id_function` suffix-strip (`_api_v1_{method}` removed per D-11-OPID); single atomic regen; `schema.d.ts` callsites updated in the same commit.
- FRZ-03: Explicit `openapi_tags=[...]` defined in `app/main.py` with stable order covering 12 domains — Auth, Users, Clients, Memberships, Visits, Schedule, Bookings, Trainers, Payments, Reports, Audit-log, Internal (Internal last); every router declares `tags=[...]` explicitly — no auto-derived tags.
- FRZ-04: `info{}` metadata complete under clubcore name — `title`, `version`, `description` with contract-freeze statement; `servers=[{url:"http://localhost:8000", description:"Local dev"}]`; `contact`/`license` explicitly omitted (private commercial project, D-11-DOCS-PRIVATE).
- FRZ-05: `securitySchemes` wired — `cookieAuth` (`cc_access` httpOnly cookie) + `csrfHeader` (`X-CSRF-Token` header); `clubcore_csrf` non-httpOnly readable cookie for double-submit CSRF; public endpoints (`/healthz`, auth/login, OTP, Telegram, `_internal/*`) override to `security: []`.
- FRZ-06: Shared `components.responses` defined for the six common error envelopes (`401_Unauthorized`, `403_Forbidden`, `404_NotFound`, `409_Conflict`, `422_ValidationError`, `429_RateLimited`) matching the `{code, message, fields}` backend envelope; all usage sites migrated to `$ref`.
- FRZ-07: Redocly CLI lint config (`redocly.yaml` at repo root, `extends: recommended`) added; `npx @redocly/cli@latest lint apps/backend/openapi.json` exits 0; wired as the 7th parallel CI gate in `.github/workflows/ci.yml` (`redocly-lint` job).
- FRZ-08: Pre-freeze drift baseline captured — `git diff --exit-code apps/backend/openapi.json packages/api-client/src/schema.d.ts` clean after curation; annotated baseline tag `contract-freeze-v1.11.0` created; this CHANGELOG entry records the freeze.

### Notes

- Doc-site is private per D-11-DOCS-PRIVATE; no public publish path. `pnpm docs` runs a local Redocly preview-docs instance only.
- Operation IDs cleaned via `generate_unique_id_function` suffix-strip per D-11-OPID (not explicit per-route `operation_id=` annotations — single atomic diff vs 103 edit sites).
